========================================
JavaScript: console, DevTools и Node REPL
========================================


1. console — базовое понимание
--------------------------------

console — встроенный объект (Web API в браузере / API Node.js),
предназначенный для вывода и отладки информации.

Доступ к методам осуществляется через точку:

console.log
console.dir
console.table


console.log() — вывод данных в стандартный поток вывода (stdout)

Свойства:
- используется для вывода информации
- возвращает undefined
- не предназначен для вычислений


console.dir() — выводит структуру объекта
- удобен для просмотра вложенных объектов


console.table() — выводит данные в табличном виде
- удобен для массивов и объектов


Пример:

console.log('Hello World')


Разбор:
console — объект
. — доступ к свойствам объекта (точечная запись)
log — метод объекта console
() — вызов метода


========================================


2. Браузерная консоль (DevTools)
---------------------------------

Пример:

console.log('Igor')

Вывод:
Igor

Возвращаемое значение:
undefined


Пояснение:
- Igor — результат работы console.log
- undefined — возвращаемое значение функции


Дополнительный служебный вывод:
VMxxx:1

Пояснение:
- VMxxx — виртуальный скрипт Chrome DevTools
- не является частью JavaScript
- используется для идентификации кода, введённого в консоль


---------------------------------

Ввод объекта console:

console

Результат:
Console {debug: ƒ, error: ƒ, info: ƒ, log: ƒ, warn: ƒ, …}

или раскрытый список методов:
- debug()
- error()
- info()
- log()
- warn()
- и другие


Пояснение:
- это НЕ выполнение кода
- это инспекция объекта (просмотр его структуры)
- DevTools показывает содержимое объекта


========================================


3. Node.js REPL (интерактивный режим)
--------------------------------------

Запуск:

node


Пример:

> console.log('Igor')
Igor
undefined


Особенности:
- выполняет код построчно
- сразу показывает результат выражений
- console.log выводит данные в stdout
- undefined — возвращаемое значение функции


Выход:
.exit
или Ctrl + C / Ctrl + D


========================================


4. Запуск Node.js файлов
--------------------------------------

Пример:

node index.js


Особенности:
- выполняется весь файл целиком
- вывод только через console.*
- результат выражений не отображается автоматически


========================================


5. Главное различие сред выполнения
--------------------------------------

JavaScript выполняется в разных средах:

1) Браузер (DevTools Console)
2) Node.js REPL
3) Node.js файл (node index.js)

Различия:
- синтаксис JavaScript одинаковый
- отличается только среда выполнения и отображение вывода
