========================================
7. ВЫРАЖЕНИЯ (EXPRESSIONS)
========================================

Выражение (expression) — это конструкция JavaScript,
которая вычисляется и возвращает значение.

Примеры выражений:

'abc'
10
5 + 2
c = 10
'Good ' + 'Evening'
a <= b || c !== d
myFunction(c, d)


----------------------------------------
Результат выражения
----------------------------------------

Результатом каждого выражения является значение.

Примеры:

'abc'                → 'abc'
10                   → 10
a + b                → сумма значений a и b
'Good ' + 'Evening'  → 'Good Evening'
a <= b || c !== d    → true или false
myFunction(c, d)     → значение, возвращённое функцией


========================================
8. ВЫРАЖЕНИЕ ПРИСВАИВАНИЯ
========================================

a = 20

Что происходит:
1. Значение 20 присваивается переменной a
2. Выражение возвращает значение 20

Результат:

a = 20 → 20


----------------------------------------
Пример:

a = 20
→ возвращает 20


========================================
9. ВЫРАЖЕНИЯ С ПОБОЧНЫМИ ДЕЙСТВИЯМИ
========================================

Некоторые выражения не только возвращают значение,
но и выполняют дополнительные действия.

Это называется побочным эффектом (side effect).


----------------------------------------
Пример 1:

a = 5

Побочный эффект:
- изменяется значение переменной a

Результат:
5


----------------------------------------
Пример 2:

b++

Побочный эффект:
- значение переменной увеличивается на 1

Пример:

b = 5
b++

Результат выражения:
5

Новое значение b:
6


----------------------------------------
Пример 3:

myFunction(c, d)

Побочные эффекты:
- изменение данных
- вывод в консоль
- другие действия

Результат:
значение, возвращённое через return


========================================
ГЛАВНЫЕ ИДЕИ РАЗДЕЛА
========================================

1. Выражение всегда возвращает значение.

2. Некоторые выражения только вычисляются:
   - 10
   - 'abc'
   - a + b

3. Некоторые выражения изменяют состояние программы:
   - a = 5
   - b++
   - функции с побочными эффектами

4. Присваивание — это тоже выражение.

5. Побочные эффекты — это изменения вне самого результата выражения.
