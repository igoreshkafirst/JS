========================================
9. ОБЪЯВЛЕНИЕ ПЕРЕМЕННЫХ
========================================

Переменные используются для хранения данных.

----------------------------------------
Объявление
----------------------------------------

let a

Создаётся переменная a.

После объявления значение равно:

undefined

----------------------------------------
Объявление и присваивание
----------------------------------------

let a = 10

const c = 10

Переменная создаётся и сразу получает значение.

----------------------------------------
Присваивание
----------------------------------------

a = true

Переменной присваивается новое значение.

----------------------------------------
Пример работы с let
----------------------------------------

let a = 10

a = 20

let b

b = false

Итог:

a → 20
b → false

----------------------------------------
Пример работы с const
----------------------------------------

const c = 10

c = 20

Ошибка:

TypeError: Assignment to constant variable.

Значение переменной const нельзя переназначить.

----------------------------------------
Использование переменной
----------------------------------------

console.log(a)

let a

Ошибка:

ReferenceError: Cannot access 'a' before initialization

Переменную let нельзя использовать до объявления.

----------------------------------------
После объявления
----------------------------------------

let a

console.log(a)

Результат:

undefined

Переменная существует, но значение ещё не присвоено.

----------------------------------------
После присваивания
----------------------------------------

let a

console.log(a)

a = true

console.log(a)

Результат:

undefined
true

========================================
ГЛАВНЫЕ ИДЕИ
========================================

let — переменная, значение можно изменять.

const — переменная, значение нельзя переназначить.

Объявление:
let a

Присваивание:
a = true

Объявление и присваивание:
let a = 10
const c = 10

Переменные let и const нельзя использовать до объявления.

Неинициализированная переменная имеет значение undefined.
