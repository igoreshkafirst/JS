========================================
10. ПРАКТИКА ПО СОЗДАНИЮ ПЕРЕМЕННЫХ
========================================

----------------------------------------
Создание переменной
----------------------------------------

let myName;

Переменная объявлена, но значение не присвоено.

----------------------------------------
Проверка значения
----------------------------------------

console.log(myName);

Результат:

undefined

Причина:
переменная существует, но пока не содержит значения.

----------------------------------------
Присваивание значения
----------------------------------------

myName = 'Igor';

Теперь переменная хранит строку:

'Igor'

----------------------------------------
Повторная проверка
----------------------------------------

console.log(myName);

Результат:

Igor

----------------------------------------
Интересный пример
----------------------------------------

console.log(console.log(10));

Порядок выполнения:

1. Выполняется внутренний вызов:

   console.log(10)

   Вывод:

   10

2. console.log() ничего не возвращает

   Результат:

   undefined

3. Внешний console.log() выводит это значение

   Вывод:

   undefined

Итоговый вывод в консоли:

10
undefined

========================================
ГЛАВНЫЕ ИДЕИ
========================================

let myName;
→ объявление переменной

myName = 'Igor';
→ присваивание значения

console.log(myName);
→ вывод значения в консоль

Неинициализированная переменная имеет значение:

undefined

Функция console.log():

- выводит данные в консоль
- возвращает undefined
