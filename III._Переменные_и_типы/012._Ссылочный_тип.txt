========================================
12. ССЫЛОЧНЫЙ ТИП ДАННЫХ
========================================

Объекты хранятся и копируются по ссылке.

----------------------------------------
Пример
----------------------------------------

const objectA = {
  a: 10,
  b: true,
};

const copyOfA = objectA;

----------------------------------------
Изменение свойства
----------------------------------------

copyOfA.a = 20;

Результат:

objectA.a → 20

Причина:

objectA и copyOfA содержат ссылку
на один и тот же объект.

----------------------------------------
Добавление нового свойства
----------------------------------------

copyOfA.c = 'abc';

Результат:

objectA.c → 'abc'

Причина:

изменяется тот же самый объект.

----------------------------------------
Схема
----------------------------------------

objectA ──┐
          │
          ▼
      {
        a: 10,
        b: true
      }
          ▲
          │
copyOfA ──┘

После:

copyOfA.a = 20

получаем:

{
  a: 20,
  b: true
}

----------------------------------------
Главная идея
----------------------------------------

const copyOfA = objectA;

не создаёт копию объекта.

Создаётся новая ссылка
на существующий объект.

Поэтому изменения через objectA
или copyOfA видны через обе переменные.
