========================================
13. ДИНАМИЧЕСКАЯ ТИПИЗАЦИЯ
========================================

----------------------------------------
Статическая типизация
----------------------------------------

String a = 'abc';
int b = 10;

b = 'xyz'; // Error

Особенность:

Тип переменной задаётся при объявлении
и не может быть изменён.

----------------------------------------
Динамическая типизация
----------------------------------------

a = 'abc'; // String
a = 10;    // Number

Особенность:

Тип переменной может изменяться
во время выполнения программы.

----------------------------------------
Динамическая типизация в JavaScript
----------------------------------------

Пример 1

let a = 10;

a = true;
a = 'Igor';
a = undefined;

Результат:

Переменная a последовательно хранит значения
разных типов данных.

----------------------------------------
Пример 2
----------------------------------------

function a() {
  console.log('Hey there');
}

a(); // Hey there

a = 10;

a(); // Uncaught TypeError: a is not a function

Объяснение:

Сначала a содержит функцию.

После:

a = 10;

переменная содержит число.

Попытка вызвать число как функцию
приводит к ошибке:

TypeError: a is not a function

----------------------------------------
const для объявления переменных
----------------------------------------

const a = () => {
  console.log('Hey there');
};

a(); // Hey there

a = 10;

TypeError: Assignment to constant variable.

a();

Объяснение:

Переменная, объявленная через const,
не может быть переназначена.

Поэтому инструкция:

a = 10;

вызывает ошибку:

TypeError: Assignment to constant variable.

Значение переменной остаётся прежним.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

JavaScript использует динамическую типизацию.

Одна и та же переменная может хранить:

- Number
- Boolean
- String
- Undefined
- Function
- Object
- другие типы данных

Тип определяется значением,
а не объявлением переменной.

let позволяет изменять значение переменной.

const запрещает переназначение переменной.
