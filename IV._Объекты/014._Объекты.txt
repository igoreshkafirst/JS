========================================
14. ОБЪЕКТЫ
========================================

----------------------------------------
Структура и синтаксис объекта
----------------------------------------

const myCity = {
  city: 'New York',
  popular: true,
  country: 'USA',
};

Свойство (property) — имя поля объекта.

Значение (value) — данные, хранящиеся в свойстве.

Пример:

city     → свойство
'New York' → значение

----------------------------------------
Порядок свойств объекта
----------------------------------------

const myCity = {
  city: 'New York',
  popular: true,
  country: 'USA',
};

Технически одинаковый объект:

const myCity = {
  popular: true,
  country: 'USA',
  city: 'New York',
};

Порядок свойств при создании объекта
не влияет на доступ к ним.

----------------------------------------
Получение значений свойств
----------------------------------------

const myCity = {
  city: 'New York',
  popular: true,
  country: 'USA',
};

console.log(myCity.city);

Результат:

New York

----------------------------------------

console.log(myCity.popular);

Результат:

true

----------------------------------------
Точечная запись
----------------------------------------

myCity.city

Используется для доступа
к свойствам объекта.

Синтаксис:

объект.свойство

----------------------------------------
Изменение значений свойств
----------------------------------------

const myCity = {
  city: 'New York',
};

myCity.city = 'Las Vegas';

console.log(myCity.city);

Результат:

Las Vegas

----------------------------------------
Важно
----------------------------------------

const запрещает переназначение переменной:

const myCity = {};

myCity = {};

TypeError: Assignment to constant variable.

Но изменение свойств объекта разрешено:

const myCity = {
  city: 'New York',
};

myCity.city = 'Las Vegas';

Это работает без ошибок.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Объект — это набор свойств.

Свойство состоит из:

имя → значение

Пример:

city → 'New York'

Для доступа к свойствам используется
точечная запись:

myCity.city

Свойства объекта можно изменять:

myCity.city = 'Las Vegas'

Объект, объявленный через const,
можно изменять, но нельзя переназначать.
