========================================
15. СОЗДАНИЕ И УДАЛЕНИЕ СВОЙСТВ ОБЪЕКТОВ
========================================

----------------------------------------
Добавление новых свойств
----------------------------------------

const myCity = {
  city: 'New York',
};

myCity.popular = true;

console.log(myCity);

Результат:

{
  city: 'New York',
  popular: true
}

----------------------------------------

myCity.country = 'USA';

console.log(myCity);

Результат:

{
  city: 'New York',
  popular: true,
  country: 'USA'
}

----------------------------------------
Вывод
----------------------------------------

Новые свойства можно добавлять
после создания объекта.

Синтаксис:

объект.свойство = значение

----------------------------------------
Удаление свойств
----------------------------------------

const myCity = {
  city: 'New York',
  popular: true,
  country: 'USA',
};

delete myCity.country;

console.log(myCity);

Результат:

{
  city: 'New York',
  popular: true
}

----------------------------------------
Вывод
----------------------------------------

Оператор delete удаляет свойство объекта.

Синтаксис:

delete объект.свойство

----------------------------------------
Доступ к свойствам через скобки
----------------------------------------

const myCity = {
  city: 'New York',
};

myCity['popular'] = true;

console.log(myCity);

Результат:

{
  city: 'New York',
  popular: true
}

----------------------------------------
Использование переменной
----------------------------------------

const countryPropertyName = 'country';

myCity[countryPropertyName] = 'USA';

console.log(myCity);

Результат:

{
  city: 'New York',
  popular: true,
  country: 'USA'
}

----------------------------------------
Вывод
----------------------------------------

Через квадратные скобки можно использовать:

- строку

myCity['country']

- переменную

myCity[countryPropertyName]

----------------------------------------
Сравнение способов доступа
----------------------------------------

Точечная запись:

myCity.country

С помощью скобок:

myCity['country']

Оба варианта обращаются
к одному и тому же свойству.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Добавление свойства:

myCity.country = 'USA'

Удаление свойства:

delete myCity.country

Доступ через точку:

myCity.country

Доступ через скобки:

myCity['country']

Через квадратные скобки можно
использовать переменные.
