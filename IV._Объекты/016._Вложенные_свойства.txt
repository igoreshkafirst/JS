========================================
16. ВЛОЖЕННЫЕ СВОЙСТВА
========================================

----------------------------------------
Объект внутри объекта
----------------------------------------

const myCity = {
  city: 'New York',
  info: {
    isPopular: true,
    country: 'USA',
  },
};

Структура объекта:

myCity
│
├── city
│   └── 'New York'
│
└── info
    ├── isPopular
    │   └── true
    └── country
        └── 'USA'

----------------------------------------
Доступ к вложенным свойствам
----------------------------------------

console.log(myCity.info.isPopular);

Результат:

true

Используется цепочка свойств:

myCity.info.isPopular

Сначала:

myCity.info

затем:

info.isPopular

----------------------------------------
Удаление вложенного свойства
----------------------------------------

delete myCity.info['isPopular'];

После удаления объект выглядит так:

{
  city: 'New York',
  info: {
    country: 'USA'
  }
}

----------------------------------------
Проверка результата
----------------------------------------

console.log(myCity);

Результат:

{
  city: 'New York',
  info: {
    country: 'USA'
  }
}

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Объект может содержать другие объекты.

Такие объекты называются вложенными.

Доступ к вложенным свойствам:

myCity.info.country

Удаление вложенного свойства:

delete myCity.info['isPopular']

Точечную запись и квадратные скобки
можно комбинировать:

myCity.info.country

myCity.info['country']
