========================================
17. СОКРАЩЁННЫЙ ФОРМАТ ЗАПИСИ СВОЙСТВ
========================================

----------------------------------------
Использование переменных
----------------------------------------

const name = 'Igor';
const postsQty = 23;

const userProfile = {
  name: name,
  postsQty: postsQty,
  hasSignedAgreement: false,
};

Результат:

{
  name: 'Igor',
  postsQty: 23,
  hasSignedAgreement: false
}

----------------------------------------
Пояснение
----------------------------------------

Свойства объекта получают значения
из одноимённых переменных:

name: name

postsQty: postsQty

Левая часть:
имя свойства объекта

Правая часть:
значение переменной

----------------------------------------
Сокращённый формат записи свойств
----------------------------------------

const name = 'Igor';
const postsQty = 23;

const userProfile = {
  name,
  postsQty,
  hasSignedAgreement: false,
};

Результат:

{
  name: 'Igor',
  postsQty: 23,
  hasSignedAgreement: false
}

----------------------------------------
Пояснение
----------------------------------------

Если имя свойства объекта совпадает
с именем переменной,

вместо:

name: name

можно записать:

name

вместо:

postsQty: postsQty

можно записать:

postsQty

----------------------------------------
Сравнение
----------------------------------------

Полная запись:

const userProfile = {
  name: name,
  postsQty: postsQty,
};

Сокращённая запись:

const userProfile = {
  name,
  postsQty,
};

Результат будет одинаковым.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Если имя свойства объекта совпадает
с именем переменной,

можно использовать сокращённую запись.

Было:

name: name

Стало:

name

Было:

postsQty: postsQty

Стало:

postsQty

Сокращённая запись делает код короче
и используется очень часто.
