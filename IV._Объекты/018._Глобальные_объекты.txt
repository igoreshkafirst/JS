========================================
18. ГЛОБАЛЬНЫЕ ОБЪЕКТЫ
========================================

Глобальный объект предоставляет доступ
к встроенным функциям, свойствам и объектам
текущей среды выполнения JavaScript.

========================================
ВЕБ-БРАУЗЕР
========================================

Работа в консоли браузера.

----------------------------------------
Объект window
----------------------------------------

window

Результат:

Window {
  window: Window,
  self: Window,
  document: document,
  name: '',
  location: Location,
  ...
}

window — глобальный объект браузера.

----------------------------------------
Свойства window
----------------------------------------

window.innerWidth

Результат:

1920

innerWidth — ширина окна браузера.

----------------------------------------
globalThis
----------------------------------------

globalThis

Результат:

Window {
  window: Window,
  self: Window,
  document: document,
  name: '',
  location: Location,
  ...
}

В браузере:

window === globalThis

Результат:

true

----------------------------------------
Доступ к свойствам через globalThis
----------------------------------------

globalThis.innerWidth

Результат:

1920

========================================
КОНСОЛЬ И ГЛОБАЛЬНЫЙ ОБЪЕКТ
========================================

console.log(10)

Вывод:

10

Возвращаемое значение:

undefined

----------------------------------------

window.console.log(10)

Вывод:

10

Возвращаемое значение:

undefined

Вывод:

console является свойством объекта window.

Поэтому записи:

console.log(10)

и

window.console.log(10)

эквивалентны.

========================================
СРАВНЕНИЕ СРЕД
========================================

Веб-браузер:

window.console.log('Hello');

Node.js:

global.console.log('Hello');

Во всех современных средах:

globalThis.console.log('Hello');

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Браузер:

window — глобальный объект

Node.js:

global — глобальный объект

Универсальный способ доступа
к глобальному объекту:

globalThis

Во всех современных средах:

globalThis.console.log('Hello');

console является свойством
глобального объекта.
