========================================
19. МЕТОДЫ ОБЪЕКТА
========================================

Методы — это свойства объекта,
значениями которых являются функции.

========================================
МЕТОД ОБЪЕКТА
========================================

const myCity = {
  city: 'New York',
  cityGreeting: function () {
    console.log('Greetings!!');
  },
};

----------------------------------------
Вызов метода
----------------------------------------

myCity.cityGreeting();

Результат:

Greetings!!

----------------------------------------
Пояснение
----------------------------------------

city → обычное свойство

cityGreeting → метод объекта

Потому что значение свойства
cityGreeting является функцией.

========================================
СОКРАЩЁННЫЙ ФОРМАТ ЗАПИСИ МЕТОДОВ
========================================

Полная запись:

const myCity = {
  city: 'New York',
  cityGreeting: function () {
    console.log('Greetings!!');
  },
};

----------------------------------------

Сокращённая запись:

const myCity = {
  city: 'New York',
  cityGreeting() {
    console.log('Greetings!!');
  },
};

----------------------------------------
Вызов метода
----------------------------------------

myCity.cityGreeting();

Результат:

Greetings!!

----------------------------------------
Пояснение
----------------------------------------

Записи:

cityGreeting: function () {
  console.log('Greetings!!');
}

и

cityGreeting() {
  console.log('Greetings!!');
}

эквивалентны.

========================================
МЕТОДЫ И СВОЙСТВА ОБЪЕКТОВ
========================================

Доступ к свойству:

myCity.city

Результат:

'New York'

----------------------------------------

Вызов метода:

myCity.cityGreeting();

Результат:

Greetings!!

----------------------------------------
Разница
----------------------------------------

Свойство:

myCity.city

возвращает значение свойства.

Метод:

myCity.cityGreeting()

вызывает функцию,
которая является свойством объекта.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Метод — это свойство объекта,
содержащее функцию.

Пример свойства:

myCity.city

Пример метода:

myCity.cityGreeting()

Для вызова метода используются скобки:

myCity.cityGreeting()

Существует сокращённая запись методов:

cityGreeting() {
  ...
}
