========================================
20. JSON (JavaScript Object Notation)
========================================

JSON — текстовый формат обмена данными.

========================================
ФОРМАТ JSON
========================================

{
  "userId": 1,
  "id": 1,
  "title": "Test Title",
  "status": {
    "completed": false
  }
}

----------------------------------------
Передача данных
----------------------------------------

JSON передаётся как строка:

{"userId":1,"id":1,"title":"Test Title","status":{"completed":false}}

========================================
КОНВЕРТАЦИЯ JSON В ОБЪЕКТ
========================================

JSON.parse()

Результат:

{
  userId: 1,
  id: 1,
  title: 'Test Title',
  status: {
    completed: false
  }
}

========================================
КОНВЕРТАЦИЯ ОБЪЕКТА В JSON
========================================

JSON.stringify()

Результат:

{"userId":1,"id":1,"title":"Test Title","status":{"completed":false}}

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

const post = {
  title: 'My post',
  likesQty: 5
}

Результат:

undefined

----------------------------------------

post

Результат:

{
  title: 'My post',
  likesQty: 5
}

----------------------------------------

JSON

Результат:

JSON {
  parse: ƒ,
  stringify: ƒ,
  ...
}

----------------------------------------

JSON.stringify(post)

Результат:

'{"title":"My post","likesQty":5}'

----------------------------------------

const postStringified = JSON.stringify(post)

Результат:

undefined

----------------------------------------

JSON.parse(postStringified)

Результат:

{
  title: 'My post',
  likesQty: 5
}

========================================
ГЛАВНЫЕ ИДЕИ
========================================

JSON — текстовый формат обмена данными.

JSON.stringify()
преобразует объект в JSON-строку.

JSON.parse()
преобразует JSON-строку в объект.

JSON является встроенным глобальным объектом.
