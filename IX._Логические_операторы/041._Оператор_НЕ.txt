========================================
41. ОПЕРАТОР НЕ (!)
========================================

Оператор !

называется:

Логическое НЕ (NOT)

Он инвертирует логическое значение.

----------------------------------------

true  → false

false → true

========================================
ПРИМЕРЫ С ОПЕРАТОРОМ !
========================================

!10;          // false

!0;           // true

!'abc';       // false

!'';          // true

!true;        // false

!undefined;   // true

========================================
ЧТО ПРОИСХОДИТ
========================================

Перед применением оператора !

JavaScript сначала преобразует
значение в Boolean.

После этого результат инвертируется.

----------------------------------------

10

Boolean(10)

→ true

!true

→ false

----------------------------------------

0

Boolean(0)

→ false

!false

→ true

----------------------------------------

'abc'

Boolean('abc')

→ true

!true

→ false

----------------------------------------

''

Boolean('')

→ false

!false

→ true

----------------------------------------

undefined

Boolean(undefined)

→ false

!false

→ true

========================================
ДВОЙНОЕ ОТРИЦАНИЕ !!
========================================

Оператор !!

часто используется для быстрого
преобразования значения в Boolean.

========================================
ПРИМЕРЫ
========================================

!!10;         // true

!!0;          // false

!!'abc';      // true

!!'';         // false

!!true;       // true

!!undefined;  // false

========================================
ЧТО ПРОИСХОДИТ
========================================

Пример:

!!10

Шаг 1

!10

→ false

----------------------------------------

Шаг 2

!false

→ true

----------------------------------------

Результат:

true

========================================
ЗАЧЕМ ИСПОЛЬЗУЮТ !!
========================================

Вместо:

Boolean(value)

можно написать:

!!value

----------------------------------------

Примеры:

Boolean(10)

→ true

!!10

→ true

----------------------------------------

Boolean('')

→ false

!!''

→ false

========================================
СРАВНЕНИЕ
========================================

Boolean(10)

и

!!10

дают одинаковый результат.

----------------------------------------

Boolean('abc')

и

!!'abc'

дают одинаковый результат.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

!

инвертирует логическое значение.

----------------------------------------

Перед применением !

JavaScript выполняет
неявное преобразование в Boolean.

----------------------------------------

!!

используется для преобразования
значения в Boolean.

----------------------------------------

Примеры:

!true

→ false

!false

→ true

!!10

→ true

!!0

→ false
