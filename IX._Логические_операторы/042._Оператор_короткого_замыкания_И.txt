========================================
42. ОПЕРАТОР КОРОТКОГО ЗАМЫКАНИЯ И (&&)
========================================

Синтаксис:

Выражение1 && Выражение2

----------------------------------------

Оператор && называется:

Логическое И (AND)

========================================
ПРИНЦИП РАБОТЫ
========================================

JavaScript проверяет операнды
слева направо.

Если найдено ложное значение (falsy),
проверка прекращается.

Возвращается первое ложное значение.

----------------------------------------

Если все значения истинные (truthy),
возвращается последнее значение.

========================================
ПРИМЕРЫ
========================================

true && true

Результат:

true

----------------------------------------

true && false

Результат:

false

----------------------------------------

false && true

Результат:

false

========================================
ПРИМЕРЫ С РАЗНЫМИ ТИПАМИ
========================================

10 && 20

Результат:

20

Оба значения истинные,
поэтому возвращается последнее.

----------------------------------------

0 && 20

Результат:

0

0 является ложным значением.

----------------------------------------

'abc' && 100

Результат:

100

----------------------------------------

'' && 100

Результат:

''

Пустая строка является ложным значением.

----------------------------------------

true && 'Hello'

Результат:

'Hello'

========================================
КОРОТКОЕ ЗАМЫКАНИЕ
========================================

Если первый операнд ложный,
второй операнд не вычисляется.

Пример:

false && myFunction()

Результат:

false

Функция myFunction()
не будет вызвана.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Оператор && проверяет значения
слева направо.

----------------------------------------

Возвращает первое ложное значение.

----------------------------------------

Если ложных значений нет,
возвращает последнее значение.

----------------------------------------

При нахождении ложного значения
вычисление прекращается.

Это называется:

Короткое замыкание
(Short-Circuit Evaluation)
