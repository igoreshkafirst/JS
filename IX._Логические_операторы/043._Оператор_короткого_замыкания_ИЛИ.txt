========================================
43. ОПЕРАТОР КОРОТКОГО ЗАМЫКАНИЯ ИЛИ (||)
========================================

Синтаксис:

Выражение1 || Выражение2

----------------------------------------

Оператор || называется:

Логическое ИЛИ (OR)

========================================
ПРИНЦИП РАБОТЫ
========================================

JavaScript проверяет операнды
слева направо.

Если найдено истинное значение (truthy),
проверка прекращается.

Возвращается первое истинное значение.

----------------------------------------

Если истинных значений нет,
возвращается последнее значение.

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

'Igor' || 'Default value'

Результат:

'Igor'

----------------------------------------

'' || 'Default value'

Результат:

'Default value'

----------------------------------------

a || 'Default value'

Результат:

ReferenceError:
a is not defined

========================================
ПОЧЕМУ ВОЗНИКАЕТ ОШИБКА
========================================

Переменная:

a

не была объявлена.

Поэтому JavaScript не может
вычислить левый операнд и сразу
выдаёт ошибку.

========================================
ПРИМЕРЫ
========================================

true || false

Результат:

true

----------------------------------------

false || true

Результат:

true

----------------------------------------

0 || 100

Результат:

100

----------------------------------------

'' || 'Hello'

Результат:

'Hello'

----------------------------------------

'JavaScript' || 'Hello'

Результат:

'JavaScript'

========================================
КОРОТКОЕ ЗАМЫКАНИЕ
========================================

Если первый операнд истинный,
второй операнд не вычисляется.

Пример:

true || myFunction()

Результат:

true

Функция myFunction()
не будет вызвана.

========================================
ЧАСТОЕ ПРИМЕНЕНИЕ
========================================

Установка значения по умолчанию.

Пример:

const name = userName || 'Anonymous';

----------------------------------------

Если userName содержит
истинное значение (truthy),
оно будет использовано.

Иначе будет использовано:

'Anonymous'

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Оператор || проверяет значения
слева направо.

----------------------------------------

Возвращает первое истинное значение.

----------------------------------------

Если истинных значений нет,
возвращает последнее значение.

----------------------------------------

При нахождении истинного значения
вычисление прекращается.

Это называется:

Короткое замыкание
(Short-Circuit Evaluation)

========================================
КОНЕЦ РАЗДЕЛА
========================================
