========================================
44. ТРЮК С ОПЕРАТОРОМ И (&&)
И ВЫЗОВОМ ФУНКЦИИ
========================================

Оператор && может использоваться
для условного вызова функции.

Синтаксис:

условие && функция()

----------------------------------------

Если условие истинное (truthy),
функция будет вызвана.

Если условие ложное (falsy),
функция вызвана не будет.

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

let b = 10

Результат:

undefined

----------------------------------------

b && console.log('Выполнено!')

Результат:

Выполнено!

undefined

----------------------------------------

let c

Результат:

undefined

----------------------------------------

c && console.log('Выполнено!')

Результат:

undefined

========================================
ЧТО ПРОИСХОДИТ
========================================

Пусть:

b = 10

----------------------------------------

Выражение:

b && console.log('Выполнено!')

эквивалентно проверке:

если b является truthy,
выполнить console.log(...)

----------------------------------------

Так как:

10

является истинным значением,

вызывается:

console.log('Выполнено!')

и в консоль выводится:

Выполнено!

========================================
ВТОРОЙ ПРИМЕР
========================================

let c;

После объявления:

c === undefined

----------------------------------------

Выражение:

c && console.log('Выполнено!')

Сначала вычисляется:

undefined

----------------------------------------

undefined является falsy-значением.

Поэтому оператор && сразу
завершает вычисление.

Функция console.log(...)
не вызывается.

========================================
КОРОТКОЕ ЗАМЫКАНИЕ
========================================

При ложном первом операнде:

false && myFunction()

myFunction() не выполняется.

----------------------------------------

При истинном первом операнде:

true && myFunction()

myFunction() выполняется.

========================================
АНАЛОГ ЧЕРЕЗ IF
========================================

Запись:

b && console.log('Выполнено!')

аналогична:

if (b) {
  console.log('Выполнено!');
}

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Оператор && может использоваться
для условного выполнения кода.

----------------------------------------

Если первый операнд truthy,
второй операнд вычисляется.

----------------------------------------

Если первый операнд falsy,
вычисление прекращается.

----------------------------------------

Такой приём основан на механизме
короткого замыкания (short-circuit).
