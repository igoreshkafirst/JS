========================================
45. ЦЕПОЧКИ ВЫРАЖЕНИЙ С ОПЕРАТОРАМИ
И (&&) И ИЛИ (||)
========================================

Операторы && и || можно объединять
в длинные цепочки выражений.

========================================
ЦЕПОЧКА С ОПЕРАТОРОМ &&
========================================

a && b && c && d

----------------------------------------
ПРИНЦИП РАБОТЫ
----------------------------------------

Проверка выполняется слева направо.

JavaScript ищет первое ложное
значение (falsy).

Если такое значение найдено,
вычисление прекращается.

Возвращается первое ложное значение.

----------------------------------------

Если все значения истинные (truthy),
возвращается последнее значение.

========================================
ПРИМЕРЫ
========================================

10 && 20 && 30

Результат:

30

----------------------------------------

10 && 0 && 30

Результат:

0

----------------------------------------

'abc' && true && 100

Результат:

100

========================================
ЦЕПОЧКА С ОПЕРАТОРОМ ||
========================================

a || b || c || d

----------------------------------------
ПРИНЦИП РАБОТЫ
----------------------------------------

Проверка выполняется слева направо.

JavaScript ищет первое истинное
значение (truthy).

Если такое значение найдено,
вычисление прекращается.

Возвращается первое истинное значение.

----------------------------------------

Если истинных значений нет,
возвращается последнее значение.

========================================
ПРИМЕРЫ
========================================

0 || '' || 'Hello'

Результат:

'Hello'

----------------------------------------

null || undefined || 100

Результат:

100

----------------------------------------

false || '' || 0

Результат:

0

========================================
КОРОТКОЕ ЗАМЫКАНИЕ
========================================

Для &&

Поиск первого ложного значения.

----------------------------------------

Для ||

Поиск первого истинного значения.

----------------------------------------

После нахождения нужного значения
дальнейшие выражения не вычисляются.

========================================
СВЯЗЬ С ПРЕДЫДУЩИМИ УРОКАМИ
========================================

Урок 42:

&&

ищет первое ложное значение.

----------------------------------------

Урок 43:

||

ищет первое истинное значение.

----------------------------------------

Урок 45:

Показывает, что этот принцип
работает не только для двух,
но и для любого количества
выражений в цепочке.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

a && b && c && d

→ первое ложное значение
или последнее значение.

----------------------------------------

a || b || c || d

→ первое истинное значение
или последнее значение.

----------------------------------------

Оба оператора используют
механизм короткого замыкания
(Short-Circuit Evaluation).

========================================
