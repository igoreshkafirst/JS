========================================
21. МУТАЦИЯ В JAVASCRIPT
========================================

Мутация (mutation) — изменение существующего объекта
или массива после его создания.

========================================
ЗНАЧЕНИЯ ПРИМИТИВНЫХ ТИПОВ
========================================

const a = 10;

let b = a; // Копирование значения (copy by value)

b = 30;

console.log(a); // 10
console.log(b); // 30

----------------------------------------
Результат
----------------------------------------

a → 10
b → 30

----------------------------------------
Пояснение
----------------------------------------

При копировании примитивов создаётся
новая независимая копия значения.

Изменение переменной b
не влияет на переменную a.

========================================
ЗНАЧЕНИЯ ССЫЛОЧНОГО ТИПА
========================================

const person = {
  name: 'Bob',
  age: 21,
};

person.age = 22;

person.isAdult = true;

console.log(person.age); // 22
console.log(person.isAdult); // true

----------------------------------------
Результат
----------------------------------------

{
  name: 'Bob',
  age: 22,
  isAdult: true
}

----------------------------------------
Пояснение
----------------------------------------

Объект объявлен через const.

Несмотря на это, свойства объекта
можно изменять.

Изменяется не переменная person,
а объект, на который она ссылается.

Это называется мутацией объекта.

========================================
МУТИРОВАНИЕ КОПИЙ
========================================

const person = {
  name: 'Bob',
  age: 25,
};

const person2 = person;

person2.age = 26;

person2.isAdult = true;

----------------------------------------
Проверка
----------------------------------------

console.log(person.age); // 26
console.log(person.isAdult); // true

----------------------------------------
Результат
----------------------------------------

person:

{
  name: 'Bob',
  age: 26,
  isAdult: true
}

person2:

{
  name: 'Bob',
  age: 26,
  isAdult: true
}

----------------------------------------
Пояснение
----------------------------------------

Строка:

const person2 = person;

не создаёт новый объект.

Копируется только ссылка на объект
(copy by reference).

Переменные person и person2
ссылаются на один и тот же объект.

Поэтому изменение через person2
видно и через person.

========================================
СРАВНЕНИЕ
========================================

Примитивы:

const a = 10;
let b = a;

Копируется значение.

----------------------------------------

Объекты:

const person2 = person;

Копируется ссылка.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Примитивные типы копируются по значению
(copy by value).

Объекты копируются по ссылке
(copy by reference).

Мутация — изменение существующего объекта.

const запрещает переназначение переменной,
но не запрещает изменение свойств объекта.

После:

const person2 = person;

обе переменные указывают
на один и тот же объект.
