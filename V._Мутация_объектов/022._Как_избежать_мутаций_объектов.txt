========================================
22. КАК ИЗБЕЖАТЬ МУТАЦИЙ ОБЪЕКТОВ
========================================

При обычном копировании объекта:

const person2 = person;

копируется ссылка на объект.

Изменение person2 приводит
к изменению person.

Чтобы этого избежать,
необходимо создавать копию объекта.

========================================
ВАРИАНТ 1. Object.assign()
========================================

const person = {
  name: 'Bob',
  age: 25,
};

const person2 = Object.assign({}, person);

person2.age = 26;

console.log(person2.age); // 26
console.log(person.age);  // 25

----------------------------------------
Пояснение
----------------------------------------

Object.assign() создаёт новый объект
и копирует в него свойства исходного объекта.

Синтаксис:

Object.assign({}, объект)

----------------------------------------
Важно
----------------------------------------

Если объект содержит вложенные объекты,
то ссылки на них сохраняются.

Это поверхностная копия
(shallow copy).

========================================
ВАРИАНТ 2. ОПЕРАТОР РАЗВОРОТА (...)
========================================

const person = {
  name: 'Bob',
  age: 25,
};

const person2 = { ...person };

person2.name = 'Alice';

console.log(person2.name); // Alice
console.log(person.name);  // Bob

----------------------------------------
Пояснение
----------------------------------------

Оператор ...

копирует свойства объекта
в новый объект.

----------------------------------------
Важно
----------------------------------------

Вложенные объекты
не копируются полностью.

Ссылки на них сохраняются.

Это также поверхностная копия
(shallow copy).

========================================
ВАРИАНТ 3. JSON.parse(JSON.stringify())
========================================

const person = {
  name: 'Bob',
  age: 25,
};

const person2 =
  JSON.parse(
    JSON.stringify(person)
  );

person2.name = 'Alice';

console.log(person2.name); // Alice
console.log(person.name);  // Bob

----------------------------------------
Пояснение
----------------------------------------

JSON.stringify()

преобразует объект в JSON-строку.

JSON.parse()

создаёт новый объект
из JSON-строки.

----------------------------------------
Важно
----------------------------------------

Вложенные объекты также копируются.

Получается глубокая копия
(deep copy).

========================================
СРАВНЕНИЕ СПОСОБОВ
========================================

Object.assign({}, object)

✓ создаёт новый объект
✗ ссылки на вложенные объекты сохраняются

----------------------------------------

{ ...object }

✓ короткая запись
✗ ссылки на вложенные объекты сохраняются

----------------------------------------

JSON.parse(JSON.stringify(object))

✓ создаёт глубокую копию
✓ вложенные объекты копируются

========================================
ГЛАВНЫЕ ИДЕИ
========================================

const person2 = person

→ копируется ссылка

----------------------------------------

Object.assign({}, person)

→ поверхностная копия

----------------------------------------

{ ...person }

→ поверхностная копия

----------------------------------------

JSON.parse(JSON.stringify(person))

→ глубокая копия
