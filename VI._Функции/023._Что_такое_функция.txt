========================================
23. ЧТО ТАКОЕ ФУНКЦИЯ
========================================

Функция — это многократно используемый блок кода.

Функции позволяют избежать
повторения одинакового кода.

========================================
НЕОПТИМИЗИРОВАННОЕ РЕШЕНИЕ
========================================

let a = 5;
let b = 3;

let c;

c = a + b;
console.log(c);

a = 8;
b = 12;

c = a + b;
console.log(c);

----------------------------------------
Результат
----------------------------------------

8

20

----------------------------------------
Недостаток
----------------------------------------

Код приходится повторять
каждый раз при вычислении суммы.

========================================
ОПТИМИЗИРОВАННОЕ РЕШЕНИЕ
========================================

let a = 5;
let b = 3;

function sum(a, b) {
  const c = a + b;
  console.log(c);
}

sum(a, b);

a = 8;
b = 12;

sum(a, b);

----------------------------------------
Результат
----------------------------------------

8

20

----------------------------------------
Пояснение
----------------------------------------

Функция sum принимает два параметра:

a
b

Внутри функции вычисляется сумма:

const c = a + b;

После этого результат выводится в консоль.

----------------------------------------
Вызов функции
----------------------------------------

sum(a, b);

При вызове функции:

a и b передаются в функцию
как аргументы.

========================================
СТРУКТУРА ФУНКЦИИ
========================================

function sum(a, b) {
  const c = a + b;
  console.log(c);
}

----------------------------------------
Разбор
----------------------------------------

function
→ ключевое слово для объявления функции

sum
→ имя функции

(a, b)
→ параметры функции

{
  ...
}
→ тело функции

========================================
ФУНКЦИЯ — ЭТО ОБЪЕКТ
========================================

function myFn(a, b) {
  let c;

  a = a + 1;

  c = a + b;

  return c;
}

----------------------------------------
Пояснение
----------------------------------------

Функция в JavaScript является объектом.

Её можно:

- сохранить в переменную
- передать другой функции
- вернуть из функции
- хранить в свойствах объекта

----------------------------------------
Оператор return
----------------------------------------

return c;

return завершает выполнение функции
и возвращает значение наружу.

----------------------------------------
Пример выполнения
----------------------------------------

myFn(10, 3)

Шаг 1:

a = 10
b = 3

Шаг 2:

a = a + 1

a = 11

Шаг 3:

c = a + b

c = 14

Шаг 4:

return c

Результат:

14

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Функция — это блок кода,
который можно использовать многократно.

Функции помогают избежать
дублирования кода.

Параметры функции:

function sum(a, b)

Аргументы функции:

sum(5, 3)

return возвращает значение
из функции.

В JavaScript функция является объектом.
