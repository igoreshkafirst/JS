========================================
24. ОБЪЯВЛЕНИЕ И ВЫЗОВ ФУНКЦИИ
========================================

========================================
ПРИМЕР ФУНКЦИИ
========================================

function myFn(a, b) {
  let c;

  a = a + 1;

  c = a + b;

  return c;
}

----------------------------------------
Вызов функции
----------------------------------------

myFn(10, 3);

Результат:

14

----------------------------------------
Пошаговое выполнение
----------------------------------------

a = 10
b = 3

a = a + 1

a = 11

c = a + b

c = 14

return c

Результат:

14

========================================
ОБЪЯВЛЕНИЕ ФУНКЦИИ
========================================

function myFn(a, b) {
  ...
}

----------------------------------------
Разбор
----------------------------------------

function
→ ключевое слово

myFn
→ имя функции

(a, b)
→ параметры функции

{
  ...
}
→ тело функции

========================================
ВЫЗОВ ФУНКЦИИ
========================================

myFn(10, 3);

----------------------------------------
Разбор
----------------------------------------

10 и 3

являются аргументами функции.

Аргументы передаются
в параметры функции:

a = 10
b = 3

========================================
САМАЯ КОРОТКАЯ ФУНКЦИЯ
========================================

function myFn() {}

----------------------------------------
Вызов
----------------------------------------

myFn();

Результат:

undefined

----------------------------------------
Пояснение
----------------------------------------

Функция выполняется,
но не содержит оператор return.

Если функция ничего не возвращает явно,

JavaScript автоматически возвращает:

undefined

========================================
ПРИМЕР
========================================

function myFn() {}

const result = myFn();

console.log(result);

Результат:

undefined

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Функция объявляется с помощью:

function имя() {}

Функция вызывается так:

имя()

Параметры находятся
в объявлении функции.

Аргументы передаются
при вызове функции.

Если оператор return отсутствует,

функция возвращает:

undefined
