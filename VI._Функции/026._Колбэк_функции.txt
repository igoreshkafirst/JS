========================================
26. КОЛБЭК-ФУНКЦИИ (CALLBACK FUNCTIONS)
========================================

Колбэк-функция (callback function) —
это функция, переданная другой функции
в качестве аргумента.

========================================
ПРОСТОЙ ПРИМЕР
========================================

function anotherFunction() {
  // Действия...
}

function fnWithCallback(callbackFunction) {
  callbackFunction();
}

fnWithCallback(anotherFunction);

----------------------------------------
Разбор
----------------------------------------

anotherFunction

→ обычная функция

----------------------------------------

callbackFunction

→ параметр функции

----------------------------------------

callbackFunction()

→ вызов функции, переданной
в качестве аргумента

----------------------------------------
Что происходит
----------------------------------------

1. Создаётся функция anotherFunction

2. Создаётся функция fnWithCallback

3. Выполняется вызов:

fnWithCallback(anotherFunction);

4. Функция anotherFunction
передаётся как аргумент

5. Внутри fnWithCallback выполняется:

callbackFunction();

6. Вызывается anotherFunction

========================================
ПРИМЕР С setTimeout
========================================

function printMyName() {
  console.log('Igor');
}

setTimeout(printMyName, 1000);

----------------------------------------
Разбор
----------------------------------------

printMyName

→ функция

----------------------------------------

1000

→ время ожидания в миллисекундах

1000 мс = 1 секунда

----------------------------------------

setTimeout()

→ встроенная функция JavaScript

========================================
ЧТО ПРОИСХОДИТ
========================================

1. Создаётся функция printMyName

2. Выполняется:

setTimeout(printMyName, 1000);

3. JavaScript ожидает 1 секунду

4. После ожидания вызывается:

printMyName()

5. В консоль выводится:

Igor

========================================
ВАЖНО
========================================

Передаётся:

printMyName

без скобок

Правильно:

setTimeout(printMyName, 1000);

----------------------------------------

Неправильно:

setTimeout(printMyName(), 1000);

Во втором случае функция будет
вызвана сразу, а не через 1 секунду.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Колбэк — это функция,
переданная другой функции
как аргумент.

Пример:

fnWithCallback(anotherFunction);

----------------------------------------

Колбэк может быть вызван
внутри другой функции.

----------------------------------------

setTimeout использует колбэк:

setTimeout(printMyName, 1000);

----------------------------------------

При передаче колбэка обычно
не используются круглые скобки:

printMyName

а не

printMyName()
