========================================
28. ОБЛАСТИ ВИДИМОСТИ (SCOPE)
========================================

Область видимости определяет,
откуда доступна переменная.

========================================
ПРИМЕР
========================================

let a;
let b;

function myFn() {
  let b;

  a = true;

  b = 10;

  console.log(b); // 10
}

myFn();

console.log(a); // true
console.log(b); // undefined

========================================
ЧТО ПРОИСХОДИТ
========================================

Глобальная область видимости:

let a;
let b;

Создаются две глобальные переменные:

a
b

----------------------------------------

Внутри функции:

function myFn() {
  let b;

  a = true;

  b = 10;

  console.log(b);
}

Создаётся локальная переменная:

let b;

Она существует только
внутри функции myFn.

========================================
ВЫПОЛНЕНИЕ КОДА
========================================

Шаг 1

Глобальные переменные:

a = undefined
b = undefined

----------------------------------------

Шаг 2

Вызов функции:

myFn();

----------------------------------------

Шаг 3

Выполняется:

a = true;

Изменяется глобальная переменная a.

----------------------------------------

Шаг 4

Выполняется:

b = 10;

Изменяется локальная переменная b,
объявленная внутри функции.

----------------------------------------

Шаг 5

console.log(b);

Результат:

10

----------------------------------------

Шаг 6

После завершения функции
локальная переменная b уничтожается.

========================================
ПРОВЕРКА РЕЗУЛЬТАТА
========================================

console.log(a);

Результат:

true

----------------------------------------

console.log(b);

Результат:

undefined

========================================
ПОЧЕМУ ТАК ПРОИСХОДИТ
========================================

Существует две разные переменные b.

Глобальная:

let b;

----------------------------------------

Локальная:

function myFn() {
  let b;
}

----------------------------------------

Когда внутри функции используется b,

JavaScript сначала ищет её
в локальной области видимости.

Поэтому изменяется локальная переменная.

Глобальная переменная b
остаётся без изменений.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Переменные, объявленные вне функции,
являются глобальными.

Переменные, объявленные внутри функции,
являются локальными.

Локальные переменные доступны
только внутри функции.

Функция имеет доступ
к глобальным переменным.

Локальная переменная может скрывать
глобальную переменную с тем же именем.
