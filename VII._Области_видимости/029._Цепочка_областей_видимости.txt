========================================
29. ЦЕПОЧКА ОБЛАСТЕЙ ВИДИМОСТИ
(SCOPE CHAIN)
========================================

Цепочка областей видимости позволяет
функции получать доступ к переменным
из внешних областей видимости.

========================================
ПРИМЕР
========================================

const a = 5;

function myFn() {
  function innerFn() {
    console.log(a); // 5
  }

  innerFn();
}

myFn();

========================================
РЕЗУЛЬТАТ
========================================

5

========================================
ЧТО ПРОИСХОДИТ
========================================

Шаг 1

Создаётся глобальная переменная:

const a = 5;

----------------------------------------

Шаг 2

Создаётся функция:

myFn()

----------------------------------------

Шаг 3

Внутри myFn создаётся функция:

innerFn()

----------------------------------------

Шаг 4

Выполняется:

myFn();

----------------------------------------

Шаг 5

Внутри myFn выполняется:

innerFn();

----------------------------------------

Шаг 6

Внутри innerFn выполняется:

console.log(a);

========================================
ГДЕ JAVASCRIPT ИЩЕТ ПЕРЕМЕННУЮ a
========================================

1. Внутри innerFn

Переменная a не найдена.

↓

2. Внутри myFn

Переменная a не найдена.

↓

3. В глобальной области видимости

Найдена:

const a = 5;

↓

Вывод:

5

========================================
ЦЕПОЧКА ОБЛАСТЕЙ ВИДИМОСТИ
========================================

innerFn
    ↓
myFn
    ↓
Global Scope

JavaScript ищет переменную
от внутренней области видимости
к внешней.

========================================
ВАЖНО
========================================

Внутренняя функция имеет доступ:

✓ к своим переменным

✓ к переменным внешней функции

✓ к глобальным переменным

----------------------------------------

Внешняя функция не имеет доступа
к локальным переменным внутренней функции.

========================================
ПРИМЕР
========================================

function myFn() {
  const b = 10;

  function innerFn() {
    console.log(b);
  }

  innerFn();
}

myFn();

Результат:

10

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Цепочка областей видимости
(scope chain) используется для поиска
переменных.

Поиск идёт:

локальная область
→ внешняя область
→ глобальная область

Внутренние функции имеют доступ
к переменным внешних функций.

Если переменная не найдена ни в одной
области видимости, возникает ошибка:

ReferenceError
