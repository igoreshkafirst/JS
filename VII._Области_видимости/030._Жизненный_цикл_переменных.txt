========================================
30. ЖИЗНЕННЫЙ ЦИКЛ ПЕРЕМЕННЫХ
========================================

Жизненный цикл переменной —
это период времени от момента её создания
до момента удаления из памяти.

========================================
ПРИМЕР
========================================

let a;
let b;

function myFn() {
  let b;

  a = true;
  b = 10;

  console.log(b); // 10
}

myFn();

console.log(a); // true
console.log(b); // undefined

========================================
ЖИЗНЕННЫЙ ЦИКЛ ПЕРЕМЕННОЙ b
========================================

Глобальная переменная:

let b;

Создаётся при запуске программы.

Существует до завершения работы программы.

----------------------------------------

Локальная переменная:

function myFn() {
  let b;
}

Создаётся при вызове функции.

Существует только во время
выполнения функции.

Удаляется после завершения функции.

----------------------------------------

Поэтому:

console.log(b);

после вызова функции обращается
к глобальной переменной b.

Результат:

undefined

========================================
ЖИЗНЕННЫЙ ЦИКЛ ПЕРЕМЕННОЙ a
========================================

let a;

Создаётся в глобальной области видимости.

----------------------------------------

Во время выполнения функции:

a = true;

изменяется значение глобальной переменной.

----------------------------------------

После завершения функции
переменная a продолжает существовать.

Поэтому:

console.log(a);

Результат:

true

========================================
ГЛОБАЛЬНЫЕ И ЛОКАЛЬНЫЕ ПЕРЕМЕННЫЕ
========================================

Глобальные переменные:

- создаются вне функций
- доступны практически из любого места программы
- существуют до завершения программы

----------------------------------------

Локальные переменные:

- создаются внутри функции
- доступны только внутри функции
- существуют только во время выполнения функции

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Переменные имеют жизненный цикл.

Глобальные переменные живут дольше,
чем локальные.

Локальные переменные создаются
при вызове функции.

После завершения функции
локальные переменные удаляются.

Каждый новый вызов функции
создаёт новые локальные переменные.
