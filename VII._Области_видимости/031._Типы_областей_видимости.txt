========================================
31. ТИПЫ ОБЛАСТЕЙ ВИДИМОСТИ
========================================

========================================
НЕОБЪЯВЛЕННЫЕ ПЕРЕМЕННЫЕ
========================================

function myFn() {
  a = true;

  console.log(a); // true
}

myFn();

console.log(a); // true

========================================
РЕЗУЛЬТАТ
========================================

true
true

========================================
ЧТО ПРОИСХОДИТ
========================================

Переменная a нигде не объявлена:

нет let
нет const
нет var

Однако выполняется:

a = true;

В нестрогом режиме JavaScript
создаёт глобальную переменную автоматически.

После выполнения функции
переменная становится доступна
во всей программе.

========================================
ГЛОБАЛЬНАЯ ОБЛАСТЬ ВИДИМОСТИ
========================================

После выполнения:

a = true;

фактически получается:

var a = true;

Поэтому:

console.log(a);

выводит:

true

========================================
ВАЖНО
========================================

Необъявленные переменные считаются
плохой практикой.

Современный код должен использовать:

let

const

или

var

========================================
СТРОГИЙ РЕЖИМ
========================================

'use strict';

function myFn() {
  a = true;
}

Результат:

ReferenceError: a is not defined

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Необъявленная переменная может
автоматически стать глобальной.

Такое поведение существует
только для совместимости
со старым кодом.

В современном JavaScript следует
всегда объявлять переменные через:

let
const
var
