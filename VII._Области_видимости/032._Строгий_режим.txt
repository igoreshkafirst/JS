========================================
32. СТРОГИЙ РЕЖИМ (STRICT MODE)
========================================

Строгий режим включается директивой:

'use strict';

Он помогает находить ошибки
и делает код более безопасным.

========================================
ПРИМЕР
========================================

'use strict';

function myFn() {
  a = true;
  console.log(a);
}

myFn();

console.log(a);

========================================
РЕЗУЛЬТАТ
========================================

ReferenceError:
a is not defined

========================================
ПОЧЕМУ ВОЗНИКАЕТ ОШИБКА
========================================

Переменная a не объявлена через:

let
const
var

В обычном режиме JavaScript мог бы
автоматически создать глобальную переменную.

В строгом режиме это запрещено.

========================================
ПРАВИЛЬНЫЙ ВАРИАНТ
========================================

'use strict';

function myFn() {
  let a = true;
  console.log(a);
}

myFn();

========================================
ГЛАВНЫЕ ИДЕИ
========================================

'use strict'
включает строгий режим.

Строгий режим запрещает использование
необъявленных переменных.

Попытка выполнить:

a = true;

приводит к ошибке:

ReferenceError: a is not defined

Современный JavaScript-код рекомендуется
писать в строгом режиме.
