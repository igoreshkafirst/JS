========================================
33. ОПЕРАТОРЫ
========================================

Оператор (operator) —
это специальный символ или конструкция,
которая выполняет определённое действие.

========================================
ПРИМЕР
========================================

let a, b;

a = 10;
b = a;

let c = a + b;

console.log(c); // 20

========================================
ЧТО ПРОИСХОДИТ
========================================

Шаг 1

Объявляются переменные:

let a, b;

Значения:

a = undefined
b = undefined

----------------------------------------

Шаг 2

Выполняется присваивание:

a = 10;

Теперь:

a = 10

----------------------------------------

Шаг 3

Выполняется присваивание:

b = a;

Значение переменной a
копируется в переменную b.

Теперь:

b = 10

----------------------------------------

Шаг 4

Выполняется:

let c = a + b;

Сначала вычисляется:

10 + 10

Результат:

20

После этого:

c = 20

----------------------------------------

Шаг 5

Выполняется:

console.log(c);

Результат:

20

========================================
ОПЕРАТОР ПРИСВАИВАНИЯ
========================================

=

Примеры:

a = 10;

b = a;

c = 20;

----------------------------------------

Назначение:

присвоить значение переменной.

========================================
ОПЕРАТОР СЛОЖЕНИЯ
========================================

+

Примеры:

5 + 3

a + b

10 + 10

----------------------------------------

Назначение:

сложение чисел
или объединение строк.

========================================
ПРИОРИТЕТ ВЫПОЛНЕНИЯ
========================================

В выражении:

let c = a + b;

сначала выполняется:

a + b

а затем:

c = результат

То есть:

let c = 20;

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Оператор выполняет действие
над значениями.

Оператор присваивания:

=

назначает значение переменной.

Оператор сложения:

+

складывает значения.

В одном выражении может использоваться
несколько операторов одновременно.
