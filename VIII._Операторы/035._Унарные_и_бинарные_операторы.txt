========================================
35. УНАРНЫЕ И БИНАРНЫЕ ОПЕРАТОРЫ
========================================

Операторы различаются количеством
операндов, с которыми работают.

----------------------------------------
Операнд
----------------------------------------

Операнд — это значение, над которым
выполняется операция.

Примеры:

a + b

Операнды:

a
b

========================================
УНАРНЫЕ ОПЕРАТОРЫ
========================================

Унарный оператор работает
с одним операндом.

Примеры:

a++;

+a;

delete obj.a;

typeof a;

new Object();

----------------------------------------
Разбор
----------------------------------------

a++

Увеличение значения на 1.

----------------------------------------

+a

Преобразование значения к числу.

----------------------------------------

delete obj.a

Удаление свойства объекта.

----------------------------------------

typeof a

Определение типа значения.

----------------------------------------

new Object()

Создание нового объекта.

========================================
БИНАРНЫЕ ОПЕРАТОРЫ
========================================

Бинарный оператор работает
с двумя операндами.

Примеры:

a = 5;

a + b;

a += 5;

a === b;

a && b;

----------------------------------------
Разбор
----------------------------------------

a = 5

Оператор присваивания.

----------------------------------------

a + b

Оператор сложения.

----------------------------------------

a += 5

Сложение с присваиванием.

Эквивалентно:

a = a + 5;

----------------------------------------

a === b

Строгое сравнение.

Результат:

true
или
false

----------------------------------------

a && b

Логическое И (AND).

Возвращает результат
логического сравнения.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Унарный оператор работает
с одним операндом.

Примеры:

a++
typeof a
delete obj.a

----------------------------------------

Бинарный оператор работает
с двумя операндами.

Примеры:

a + b
a = 5
a === b
a && b

----------------------------------------

Количество операндов определяет
тип оператора.
