========================================
39. ЛОЖНЫЕ ЗНАЧЕНИЯ (FALSY VALUES)
========================================

В JavaScript некоторые значения
автоматически преобразуются в false.

Такие значения называются:

Ложные значения (Falsy Values)

========================================
ЛОЖНЫЕ ЗНАЧЕНИЯ
========================================

false

0

''

undefined

null

========================================
ПРЕОБРАЗОВАНИЕ К BOOLEAN
========================================

Для явного преобразования значения
в логический тип используется:

Boolean()

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

Boolean

Результат:

ƒ Boolean() { [native code] }

----------------------------------------

Boolean('')

Результат:

false

----------------------------------------

Boolean(undefined)

Результат:

false

----------------------------------------

Boolean(' ')

Результат:

true

----------------------------------------

Boolean(0)

Результат:

false

----------------------------------------

Boolean(5.5)

Результат:

true

========================================
ПОЧЕМУ ТАК ПРОИСХОДИТ
========================================

Пустая строка:

''

преобразуется в:

false

----------------------------------------

Строка с пробелом:

' '

не является пустой строкой.

Поэтому результат:

true

----------------------------------------

Число:

0

преобразуется в:

false

----------------------------------------

Любое ненулевое число:

1
5.5
-10

преобразуется в:

true

========================================
ПРИМЕРЫ
========================================

Boolean(false)

→ false

----------------------------------------

Boolean(0)

→ false

----------------------------------------

Boolean('')

→ false

----------------------------------------

Boolean(null)

→ false

----------------------------------------

Boolean(undefined)

→ false

----------------------------------------

Boolean('Hello')

→ true

----------------------------------------

Boolean(10)

→ true

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Ложные значения (falsy values):

false
0
''
undefined
null

----------------------------------------

Для преобразования используется:

Boolean(value)

----------------------------------------

Пустая строка:

''

→ false

----------------------------------------

Строка с пробелом:

' '

→ true

----------------------------------------

Ненулевые числа:

1
5.5
-10

→ true
