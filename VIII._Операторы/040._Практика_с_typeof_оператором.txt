========================================
40. ОПЕРАТОР TYPEOF
========================================

Оператор typeof используется
для определения типа значения.

Синтаксис:

typeof значение

или

typeof(значение)

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

typeof 10

Результат:

'number'

----------------------------------------

typeof undefined

Результат:

'undefined'

----------------------------------------

typeof 'Igor'

Результат:

'string'

----------------------------------------

typeof false

Результат:

'boolean'

========================================
ПРОВЕРКА ТИПА ЗНАЧЕНИЯ
========================================

typeof 10 === 'number'

Результат:

true

----------------------------------------

'number' === 'number'

Результат:

true

========================================
ПРОВЕРКА ПЕРЕМЕННОЙ
========================================

let isUndefined

Результат:

undefined

----------------------------------------

typeof isUndefined === 'undefined'

Результат:

true

========================================
ПОЧЕМУ ЭТО РАБОТАЕТ
========================================

После объявления:

let isUndefined;

переменная автоматически получает значение:

undefined

----------------------------------------

Оператор:

typeof isUndefined

возвращает:

'undefined'

----------------------------------------

Сравнение:

typeof isUndefined === 'undefined'

возвращает:

true

========================================
ПРИМЕРЫ
========================================

typeof 100

→ 'number'

----------------------------------------

typeof 'Hello'

→ 'string'

----------------------------------------

typeof true

→ 'boolean'

----------------------------------------

typeof undefined

→ 'undefined'

========================================
ГЛАВНЫЕ ИДЕИ
========================================

typeof определяет тип значения.

----------------------------------------

Результатом typeof всегда является строка.

Примеры:

typeof 10

→ 'number'

typeof false

→ 'boolean'

typeof 'Igor'

→ 'string'

----------------------------------------

Для проверки типа обычно используют:

typeof value === 'тип'

Пример:

typeof age === 'number'
