========================================
46. ОПЕРАТОР РАЗДЕЛЕНИЯ ОБЪЕКТА
НА СВОЙСТВА (...)
========================================

Оператор:

...

называется:

Оператор разделения объекта на свойства
(Spread Operator)

========================================
ОСНОВНАЯ ИДЕЯ
========================================

Оператор ...

копирует свойства одного объекта
в другой объект.

========================================
ПРИМЕР
========================================

const button = {
  width: 200,
  text: 'Buy',
};

const redButton = {
  ...button,
  color: 'red',
};

console.table(redButton);

========================================
РЕЗУЛЬТАТ
========================================

redButton

{
  width: 200,
  text: 'Buy',
  color: 'red'
}

========================================
ЧТО ПРОИСХОДИТ
========================================

Сначала создаётся объект:

button

{
  width: 200,
  text: 'Buy'
}

----------------------------------------

Затем:

...button

копирует все свойства объекта.

----------------------------------------

После этого добавляется новое свойство:

color: 'red'

----------------------------------------

В результате создаётся новый объект:

{
  width: 200,
  text: 'Buy',
  color: 'red'
}

========================================
ОБЪЕДИНЕНИЕ ОБЪЕКТОВ
========================================

const buttonInfo = {
  text: 'Buy',
};

const buttonStyle = {
  color: 'yellow',
  width: 200,
  height: 300,
};

const button = {
  ...buttonInfo,
  ...buttonStyle,
};

console.table(button);

========================================
РЕЗУЛЬТАТ
========================================

{
  text: 'Buy',
  color: 'yellow',
  width: 200,
  height: 300
}

========================================
ЧТО ПРОИСХОДИТ
========================================

Сначала копируются свойства:

buttonInfo

----------------------------------------

Затем копируются свойства:

buttonStyle

----------------------------------------

Все свойства объединяются
в один новый объект.

========================================
ПОРЯДОК ИМЕЕТ ЗНАЧЕНИЕ
========================================

Если одинаковое свойство встречается
в нескольких объектах,

используется значение
из последнего объекта.

Пример:

const obj1 = {
  color: 'red',
};

const obj2 = {
  color: 'blue',
};

const result = {
  ...obj1,
  ...obj2,
};

Результат:

{
  color: 'blue'
}

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Оператор ...

копирует свойства объекта.

----------------------------------------

С его помощью можно:

- создавать копии объектов
- добавлять новые свойства
- объединять объекты

----------------------------------------

При совпадении имён свойств
побеждает последнее значение.
