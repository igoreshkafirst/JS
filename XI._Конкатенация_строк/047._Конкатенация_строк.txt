========================================
47. КОНКАТЕНАЦИЯ СТРОК
========================================

Конкатенация — это объединение строк.

Для конкатенации используется
оператор:

+

========================================
КОНКАТЕНАЦИЯ СТРОК
========================================

'Hello ' + 'World'

Результат:

'Hello World'

========================================
ПЕРЕМЕННЫЕ В КОНКАТЕНАЦИИ СТРОК
========================================

const hello = 'Hello';
const world = 'World';

const greeting = hello + ' ' + world;

----------------------------------------

Результат:

'Hello World'

========================================
ШАБЛОННЫЕ СТРОКИ
========================================

const hello = 'Hello';
const world = 'World';

const greeting = `${hello} ${world}`;

----------------------------------------

Результат:

'Hello World'

========================================
ЧТО ТАКОЕ ШАБЛОННЫЕ СТРОКИ
========================================

Шаблонные строки используют:

` `

(обратные кавычки)

----------------------------------------

Значения переменных вставляются
в строку с помощью:

${ }

Пример:

`${hello} ${world}`

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

10 + 'Igor'

Результат:

'10Igor'

----------------------------------------

undefined + 'abc'

Результат:

'undefinedabc'

========================================
ПОЧЕМУ ТАК ПРОИСХОДИТ
========================================

Если один из операндов является строкой,

оператор + начинает работать
как оператор конкатенации строк.

----------------------------------------

Число:

10

преобразуется в строку:

'10'

После этого выполняется:

'10' + 'Igor'

Результат:

'10Igor'

----------------------------------------

Аналогично:

undefined

преобразуется в строку:

'undefined'

После этого выполняется:

'undefined' + 'abc'

Результат:

'undefinedabc'

========================================
ПРИМЕРЫ
========================================

'Java' + 'Script'

→ 'JavaScript'

----------------------------------------

'Age: ' + 25

→ 'Age: 25'

----------------------------------------

true + ' value'

→ 'true value'

----------------------------------------

null + ' value'

→ 'null value'

========================================
КОНКАТЕНАЦИЯ И СЛОЖЕНИЕ
========================================

Если оба операнда являются числами:

10 + 5

→ 15

----------------------------------------

Если хотя бы один операнд строка:

10 + '5'

→ '105'

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Конкатенация — это объединение строк.

----------------------------------------

Для конкатенации используется:

+

----------------------------------------

Если один из операндов строка,

JavaScript преобразует второй
операнд в строку.

----------------------------------------

Современный способ объединения строк:

`${значение}`

(шаблонные строки)

----------------------------------------

Шаблонные строки используют:

` `

и конструкцию:

${ }
