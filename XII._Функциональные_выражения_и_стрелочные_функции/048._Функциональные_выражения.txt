========================================
48. ФУНКЦИОНАЛЬНЫЕ ВЫРАЖЕНИЯ
========================================

В JavaScript функцию можно создать
двумя основными способами:

1. Объявление функции
   (Function Declaration)

2. Функциональное выражение
   (Function Expression)

========================================
ОБЪЯВЛЕНИЕ ФУНКЦИИ
========================================

function myFn(a, b) {
  let c;
  a = a + 1;
  c = a + b;
  return c;
}

----------------------------------------

Функция имеет имя:

myFn

========================================
ФУНКЦИОНАЛЬНОЕ ВЫРАЖЕНИЕ
========================================

function(a, b) {
  let c;
  a = a + 1;
  c = a + b;
  return c;
}

----------------------------------------

Это функция без имени.

Такое выражение создаёт функцию
и возвращает объект функции.

========================================
ПРИСВАИВАНИЕ ФУНКЦИОНАЛЬНОГО
ВЫРАЖЕНИЯ ПЕРЕМЕННОЙ
========================================

const myFunction = function (a, b) {
  let c;
  a = a + 1;
  c = a + b;
  return c;
};

----------------------------------------

Теперь функция доступна через
переменную:

myFunction

========================================
ВЫЗОВ ФУНКЦИИ
========================================

myFunction(5, 3);

Результат:

9

----------------------------------------

Вычисление:

a = 5

a = a + 1

a = 6

c = 6 + 3

c = 9

return 9

========================================
ФУНКЦИОНАЛЬНОЕ ВЫРАЖЕНИЕ
В КАЧЕСТВЕ АРГУМЕНТА
========================================

setTimeout(function () {
  console.log('Отложенное сообщение');
}, 1000);

----------------------------------------

Через 1000 мс (1 секунду)
в консоль будет выведено:

Отложенное сообщение

========================================
ЧТО ПРОИСХОДИТ
========================================

В функцию setTimeout передаются:

1. Функция

function () {
  console.log('Отложенное сообщение');
}

2. Время задержки

1000

----------------------------------------

После истечения времени
JavaScript вызывает переданную функцию.

========================================
СВЯЗЬ С КОЛБЭК-ФУНКЦИЯМИ
========================================

Урок 26:

Колбэк-функции

----------------------------------------

Функция:

function () {
  console.log('Отложенное сообщение');
}

является колбэком,
переданным в setTimeout.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Function Declaration

создаёт именованную функцию.

----------------------------------------

Function Expression

создаёт функцию как значение.

----------------------------------------

Функциональное выражение можно:

- сохранить в переменную
- передать в другую функцию
- вернуть из функции

----------------------------------------

Функции в JavaScript являются
обычными объектами и могут
использоваться как значения.
