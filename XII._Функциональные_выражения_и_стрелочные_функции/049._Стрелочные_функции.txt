========================================
49. СТРЕЛОЧНЫЕ ФУНКЦИИ
========================================

Стрелочная функция (Arrow Function)
— это сокращённый способ записи функции.

Синтаксис:

(параметры) => {
  тело функции
}

========================================
СТРЕЛОЧНАЯ ФУНКЦИЯ
========================================

(a, b) => {
  let c;
  a = a + 1;
  c = a + b;
  return c;
};

----------------------------------------

Функция принимает параметры:

a
b

и возвращает результат вычисления.

========================================
ПРИСВАИВАНИЕ СТРЕЛОЧНОЙ ФУНКЦИИ
ПЕРЕМЕННОЙ
========================================

const myFunction = (a, b) => {
  let c;
  a = a + 1;
  c = a + b;
  return c;
};

----------------------------------------

Вызов функции:

myFunction(5, 3);

Результат:

9

----------------------------------------

Вычисление:

a = 5

a = a + 1

a = 6

c = 6 + 3

c = 9

return 9

========================================
СТРЕЛОЧНАЯ ФУНКЦИЯ
В КАЧЕСТВЕ КОЛБЭКА
========================================

setTimeout(() => {
  console.log('Отложенное сообщение');
}, 1000);

----------------------------------------

Через 1000 мс (1 секунду)
в консоль будет выведено:

Отложенное сообщение

========================================
СОКРАЩЁННАЯ ЗАПИСЬ
========================================

Если параметр один,

круглые скобки можно оставить:

(a) => {
  // Тело функции
}

----------------------------------------

Часто записывают ещё короче:

a => {
  // Тело функции
}

========================================
НЕЯВНЫЙ RETURN
========================================

Если тело функции состоит
из одного выражения,

можно убрать фигурные скобки.

----------------------------------------

Пример:

(a, b) => a + b;

----------------------------------------

JavaScript автоматически вернёт
результат выражения.

То есть запись выше эквивалентна:

(a, b) => {
  return a + b;
};

========================================
ПРИМЕРЫ
========================================

x => x * 2

----------------------------------------

(a, b) => a + b

----------------------------------------

name => `Hello ${name}`

========================================
СВЯЗЬ С ПРЕДЫДУЩИМ УРОКОМ
========================================

Урок 48:

Function Expression

const myFunction = function(a, b) {
  return a + b;
};

----------------------------------------

Урок 49:

Arrow Function

const myFunction = (a, b) => {
  return a + b;
};

----------------------------------------

Стрелочная функция является
более короткой записью
функционального выражения.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Стрелочная функция записывается
с помощью оператора:

=>

----------------------------------------

Стрелочную функцию можно:

- присвоить переменной
- передать в другую функцию
- использовать как колбэк

----------------------------------------

При одном выражении можно
использовать неявный return.

----------------------------------------

Стрелочные функции часто используются
в современном JavaScript-коде.
