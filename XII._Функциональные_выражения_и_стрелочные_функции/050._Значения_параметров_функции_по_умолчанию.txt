========================================
50. ЗНАЧЕНИЯ ПАРАМЕТРОВ ФУНКЦИИ
ПО УМОЛЧАНИЮ
========================================

Параметрам функции можно задавать
значения по умолчанию.

Эти значения используются,
если аргумент не был передан
при вызове функции.

========================================
ПРИМЕР 1
========================================

function multByFactor(
  value,
  multiplier = 1
) {
  return value * multiplier;
}

----------------------------------------

Вызов:

multByFactor(10, 2);

Результат:

20

----------------------------------------

Вызов:

multByFactor(5);

Результат:

5

========================================
ЧТО ПРОИСХОДИТ
========================================

Если второй аргумент передан:

multiplier = 2

----------------------------------------

Если второй аргумент отсутствует:

multiplier = 1

(значение по умолчанию)

========================================
ПРИМЕР 2
========================================

const newPost = (
  post,
  addedAt = Date()
) => ({
  ...post,
  addedAt
});

----------------------------------------

Исходный объект:

const firstPost = {
  id: 1,
  author: 'Igor'
};

----------------------------------------

Вызов:

newPost(firstPost);

========================================
РЕЗУЛЬТАТ
========================================

Будет создан новый объект:

{
  id: 1,
  author: 'Igor',
  addedAt: 'текущая дата и время'
}

========================================
ЧТО ПРОИСХОДИТ
========================================

Если параметр:

addedAt

не передан,

будет вызвана функция:

Date()

----------------------------------------

Результат Date() станет
значением параметра addedAt.

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

Date

Результат:

ƒ Date() { [native code] }

----------------------------------------

console.dir(Date)

Результат:

ƒ Date()

undefined

----------------------------------------

Date()

Результат:

'Tue Jun 23 2026 21:40:28 GMT+0200
(Центральная Европа,
летнее время)'

----------------------------------------

Точная дата и время зависят
от момента выполнения кода.

========================================
ЗНАЧЕНИЯ ПО УМОЛЧАНИЮ
ИСПОЛЬЗУЮТСЯ ТОЛЬКО
ПРИ ОТСУТСТВИИ АРГУМЕНТА
========================================

function sum(a, b = 10) {
  return a + b;
}

----------------------------------------

sum(5)

Результат:

15

----------------------------------------

sum(5, 20)

Результат:

25

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Параметры функции могут иметь
значения по умолчанию.

----------------------------------------

Синтаксис:

parameter = value

----------------------------------------

Значение по умолчанию используется,
если аргумент не передан.

----------------------------------------

Значением по умолчанию может быть:

- число
- строка
- объект
- результат вызова функции

----------------------------------------

Пример:

function fn(a = 10) {}

или

function fn(date = Date()) {}
