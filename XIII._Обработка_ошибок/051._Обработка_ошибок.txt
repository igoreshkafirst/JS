========================================
51. ОБРАБОТКА ОШИБОК
========================================

Во время выполнения программы
могут возникать ошибки.

Если ошибка не обработана,
выполнение кода прекращается.

========================================
ГЕНЕРАЦИЯ ОШИБКИ
========================================

const fnWithError = () => {
  throw new Error('Some error');
};

fnWithError();

console.log('Continue...');

========================================
ЧТО ПРОИСХОДИТ
========================================

Функция:

fnWithError()

создаёт ошибку:

throw new Error('Some error');

----------------------------------------

После возникновения ошибки
выполнение программы останавливается.

----------------------------------------

Строка:

console.log('Continue...');

не будет выполнена.

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

Результат:

Uncaught Error: Some error

----------------------------------------

Uncaught означает:

ошибка не была обработана.

========================================
TRY / CATCH
========================================

Для обработки ошибок используется:

try ... catch

Синтаксис:

try {
  // Код, который может вызвать ошибку
} catch (error) {
  // Обработка ошибки
}

========================================
ПРИМЕР
========================================

const fnWithError = () => {
  throw new Error('Some error');
};

try {
  fnWithError();
} catch (error) {
  console.error(error);
  console.log(error.message);
}

console.log('Continue...');

========================================
ЧТО ПРОИСХОДИТ
========================================

1. Выполняется блок try.

2. Возникает ошибка:

   throw new Error('Some error');

3. Управление передаётся в catch.

4. Ошибка сохраняется в переменной:

   error

5. Выполняется код внутри catch.

6. После catch программа продолжает работу.

========================================
СВОЙСТВО MESSAGE
========================================

error.message

возвращает текст ошибки.

Пример:

Some error

========================================
РЕЗУЛЬТАТ В КОНСОЛИ
========================================

Error: Some error

Some error

========================================
КЛЮЧЕВЫЕ СЛОВА
========================================

throw

создаёт ошибку.

----------------------------------------

Error

создаёт объект ошибки.

----------------------------------------

try

содержит код, в котором
может возникнуть ошибка.

----------------------------------------

catch

обрабатывает возникшую ошибку.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Ошибка может остановить
выполнение программы.

----------------------------------------

throw создаёт ошибку.

----------------------------------------

try позволяет выполнить код,
который может вызвать ошибку.

----------------------------------------

catch позволяет обработать ошибку.

----------------------------------------

После обработки ошибки
выполнение программы продолжается.

----------------------------------------

error.message содержит
текст ошибки.
