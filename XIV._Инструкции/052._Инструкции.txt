========================================
52. ИНСТРУКЦИИ (STATEMENTS)
========================================

Инструкция (Statement) —
это команда JavaScript,
которая выполняет действие.

В отличие от выражений,
инструкции не обязательно
возвращают значение.

========================================
ПРИМЕРЫ ИНСТРУКЦИЙ
========================================

let a;

----------------------------------------

const b = 5;

----------------------------------------

if (a > b) {
  console.log('a is larger');
}

----------------------------------------

for (let i = 0; i < 5; i++) {
  console.log(i);
}

========================================
ОБЪЯВЛЕНИЕ ПЕРЕМЕННОЙ
========================================

let a;

----------------------------------------

Создаётся переменная:

a

----------------------------------------

После объявления:

a === undefined

========================================
ОБЪЯВЛЕНИЕ И ПРИСВАИВАНИЕ
========================================

const b = 5;

----------------------------------------

Создаётся константа:

b

----------------------------------------

Ей сразу присваивается значение:

5

========================================
УСЛОВНАЯ ИНСТРУКЦИЯ IF
========================================

if (a > b) {
  console.log('a is larger');
}

----------------------------------------

Если условие истинно,

выполняется код внутри блока.

----------------------------------------

Если условие ложно,

код внутри блока не выполняется.

========================================
ЦИКЛ FOR
========================================

for (let i = 0; i < 5; i++) {
  console.log(i);
}

----------------------------------------

Структура цикла:

for (
  инициализация;
  условие;
  изменение
)

----------------------------------------

В данном примере:

let i = 0

создание переменной.

----------------------------------------

i < 5

условие продолжения цикла.

----------------------------------------

i++

увеличение значения на 1
после каждой итерации.

========================================
РЕЗУЛЬТАТ
========================================

0
1
2
3
4

========================================
ВЫРАЖЕНИЯ И ИНСТРУКЦИИ
========================================

Выражение:

5 + 2

возвращает значение:

7

----------------------------------------

Инструкция:

if (...) { }

выполняет действие.

----------------------------------------

Инструкция:

for (...) { }

организует цикл.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Statement (инструкция) —
команда JavaScript.

----------------------------------------

Инструкции управляют
выполнением программы.

----------------------------------------

Примеры инструкций:

let
const
if
for

----------------------------------------

Выражение вычисляет значение.

----------------------------------------

Инструкция выполняет действие.
