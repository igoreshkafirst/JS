========================================
53. ВЫРАЖЕНИЯ-ИНСТРУКЦИИ
(EXPRESSION STATEMENTS)
========================================

Некоторые инструкции состоят
из одного выражения.

Такие инструкции называются:

Expression Statements
(выражения-инструкции)

========================================
ПРИМЕРЫ
========================================

'abc';

----------------------------------------

a = a + 3;

----------------------------------------

c = a + b;

----------------------------------------

d = 'Good ' + 'Evening';

----------------------------------------

myFunction(c, d);

----------------------------------------

console.log('Hey');

========================================
ЧТО ПРОИСХОДИТ
========================================

Каждое выражение вычисляется.

После этого результат обычно
не используется.

========================================
ПРИМЕР
========================================

'abc';

----------------------------------------

Строка вычисляется.

Результат:

'abc'

----------------------------------------

Но значение никуда не сохраняется.

========================================
ПРИМЕР
========================================

a = a + 3;

----------------------------------------

Вычисляется:

a + 3

После этого результат
присваивается переменной a.

========================================
ПРИМЕР
========================================

c = a + b;

----------------------------------------

Вычисляется:

a + b

Результат сохраняется в c.

========================================
ПРИМЕР
========================================

d = 'Good ' + 'Evening';

----------------------------------------

Конкатенация строк
(объединение строк).

Результат:

'Good Evening'

========================================
ПРИМЕР
========================================

myFunction(c, d);

----------------------------------------

Вызывается функция.

Выполняется код внутри функции.

========================================
ПРИМЕР
========================================

console.log('Hey');

----------------------------------------

Вызывается метод:

console.log()

Результат вывода:

Hey

========================================
ПОЧЕМУ НУЖНА ТОЧКА С ЗАПЯТОЙ
========================================

Во всех примерах используется:

;

----------------------------------------

Точка с запятой завершает
выражение-инструкцию.

========================================
ВЫРАЖЕНИЕ И ВЫРАЖЕНИЕ-ИНСТРУКЦИЯ
========================================

Выражение:

'abc'

возвращает значение:

'abc'

----------------------------------------

Выражение-инструкция:

'abc';

является отдельной инструкцией.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Expression Statement —
инструкция, состоящая
из одного выражения.

----------------------------------------

Сначала вычисляется выражение.

----------------------------------------

После этого инструкция считается
выполненной.

----------------------------------------

Примеры:

a = a + 3;

c = a + b;

myFunction(c, d);

console.log('Hey');
