========================================
54. КАК ОТЛИЧИТЬ ИНСТРУКЦИЮ
ОТ ВЫРАЖЕНИЯ
========================================

Главное правило:

Выражение возвращает значение.

Инструкция выполняет действие.

========================================
ПРИМЕР
========================================

function myFn(a) {
  console.log(a);
}

const b = true;
let c = 10;

myFn(2 + 3);

myFn(b);

myFn(c = c + 1);

========================================
ПРИМЕР 1
========================================

myFn(2 + 3);

----------------------------------------

Выражение:

2 + 3

возвращает значение:

5

----------------------------------------

Вызов функции:

myFn(5);

Результат:

5

========================================
ПРИМЕР 2
========================================

myFn(b);

----------------------------------------

Выражение:

b

возвращает значение:

true

----------------------------------------

Вызов функции:

myFn(true);

Результат:

true

========================================
ПРИМЕР 3
========================================

myFn(c = c + 1);

----------------------------------------

Выражение:

c = c + 1

возвращает значение.

----------------------------------------

Если:

c = 10

то после вычисления:

c = 11

----------------------------------------

В функцию передаётся:

11

----------------------------------------

Результат:

11

========================================
ПОЧЕМУ ЭТО РАБОТАЕТ
========================================

Присваивание является выражением.

Оно не только изменяет переменную,
но и возвращает присвоенное значение.

========================================
ПРИМЕР ОШИБКИ
========================================

myFn(c = c + 1;)

----------------------------------------

Результат:

SyntaxError

----------------------------------------

Причина:

точка с запятой внутри списка
аргументов функции недопустима.

========================================
ПРИМЕР ОШИБКИ
========================================

myFn(let d)

----------------------------------------

Результат:

SyntaxError

----------------------------------------

Причина:

let d

является инструкцией объявления
переменной.

----------------------------------------

Инструкции нельзя передавать
в качестве аргументов функции.

========================================
ПРОСТОЙ СПОСОБ ПРОВЕРКИ
========================================

Спроси себя:

"Можно ли подставить результат
вместо этого кода?"

Если да — это выражение.

----------------------------------------

Примеры выражений:

2 + 3

b

c = c + 1

'Hello'

true

myFunction()

}

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Выражение возвращает значение.

----------------------------------------

Инструкция выполняет действие.

----------------------------------------

Аргументы функции должны быть
выражениями.

----------------------------------------

Присваивание является выражением.

----------------------------------------

Инструкции нельзя использовать
там, где ожидается выражение.
