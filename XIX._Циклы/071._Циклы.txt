========================================
71. ЦИКЛЫ
========================================

Циклы позволяют
многократно выполнять
один и тот же код.

========================================
БЕЗ ЦИКЛА
========================================

let i = 0;

console.log(i);

i++;

console.log(i);

i++;

console.log(i);

i++;

console.log(i);

i++;

console.log(i);

i++;

========================================
РЕЗУЛЬТАТ
========================================

0

1

2

3

4

========================================
ЧТО ПРОИСХОДИТ
========================================

После каждого:

i++;

значение переменной
увеличивается на 1.

Последнее увеличение
делает i равным 5,

но это значение
уже не выводится.

========================================
ПЕРЕБОР МАССИВА
========================================

const myArray = [
  true,
  'abc',
  10
];

console.log(myArray[0]);
console.log(myArray[1]);
console.log(myArray[2]);

========================================
РЕЗУЛЬТАТ
========================================

true

abc

10

========================================
ПЕРЕБОР ОБЪЕКТА
========================================

const myObject = {
  x: 10,
  y: true,
  z: 'abc',
};

console.log(myObject.x);
console.log(myObject.y);
console.log(myObject.z);

========================================
РЕЗУЛЬТАТ
========================================

10

true

abc

========================================
ЗАЧЕМ НУЖНЫ ЦИКЛЫ
========================================

Если элементов мало,

такой код ещё можно написать.

----------------------------------------

Но если элементов:

100

1000

10000

то писать каждую строку
вручную неудобно.

Именно для этого
используются циклы.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Циклы позволяют
повторять один и тот же код.

----------------------------------------

Без циклов приходится
многократно писать
одинаковые инструкции.

----------------------------------------

Циклы особенно полезны
при работе с массивами
и объектами.
