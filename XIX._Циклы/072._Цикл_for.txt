========================================
72. ЦИКЛ FOR
========================================

Цикл for используется,
когда заранее известно,
сколько раз нужно
повторить выполнение кода.

========================================
СИНТАКСИС
========================================

for (
  инициализация;
  условие;
  итерация
) {

  // Код,
  // выполняемый на каждой итерации

}

========================================
ЧАСТИ ЦИКЛА
========================================

1. Инициализация

Выполняется один раз
перед началом цикла.

----------------------------------------

2. Условие

Проверяется
перед каждой итерацией.

Если условие истинно,
цикл продолжается.

Если ложно —
цикл завершается.

----------------------------------------

3. Итерация

Выполняется
после каждой итерации.

Обычно изменяет
счётчик цикла.

========================================
ПРИМЕР
========================================

for (let i = 0; i < 5; i++) {
  console.log(i);
}

========================================
ВАЖНО
========================================

Инициализация
выполняется только один раз.

----------------------------------------

Условие проверяется
перед каждой итерацией.

----------------------------------------

Итерация выполняется
после каждой итерации цикла.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Цикл for используется
для повторения кода.

----------------------------------------

Он состоит из трёх частей:

инициализация;

условие;

итерация.

----------------------------------------

Цикл продолжается,
пока условие истинно.

----------------------------------------

Когда условие становится ложным,
цикл завершается.
