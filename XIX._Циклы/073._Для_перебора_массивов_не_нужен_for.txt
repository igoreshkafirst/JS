========================================
73. ДЛЯ ПЕРЕБОРА МАССИВОВ
НЕ ОБЯЗАТЕЛЬНО ИСПОЛЬЗОВАТЬ FOR
========================================

Массивы можно перебирать
обычным циклом for.

Но чаще используют
специальные методы массива.

========================================
ПЕРЕБОР С ПОМОЩЬЮ FOR
========================================

const myArray = [
  'first',
  'second',
  'third'
];

for (
  let i = 0;
  i < myArray.length;
  i++
) {
  console.log(myArray[i]);
}

========================================
РЕЗУЛЬТАТ
========================================

first

second

third

========================================
КАК РАБОТАЕТ
========================================

i = 0

↓

myArray[0]

↓

first

----------------------------------------

i = 1

↓

myArray[1]

↓

second

----------------------------------------

i = 2

↓

myArray[2]

↓

third

========================================
ПЕРЕБОР С ПОМОЩЬЮ forEach
========================================

const myArray = [
  'first',
  'second',
  'third'
];

myArray.forEach(
  (element, index) => {

    console.log(element, index);

  }
);

========================================
РЕЗУЛЬТАТ
========================================

first 0

second 1

third 2

========================================
ПАРАМЕТРЫ forEach
========================================

element

↓

Текущий элемент массива.

----------------------------------------

index

↓

Индекс текущего элемента.

========================================
СРАВНЕНИЕ
========================================

for

↓

Работает с любыми
повторяющимися действиями.

----------------------------------------

forEach

↓

Предназначен специально
для перебора массива.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Массив можно перебирать
с помощью for.

----------------------------------------

Для массивов существует
метод forEach.

----------------------------------------

forEach автоматически
перебирает все элементы массива.

----------------------------------------

В callback-функцию
передаются:

element

и

index.
