========================================
74. ЦИКЛ WHILE
========================================

Цикл while выполняет код,

пока указанное условие
остаётся истинным.

========================================
СИНТАКСИС
========================================

while (условие) {

  // Код

}

========================================
ПРИМЕР
========================================

let i = 0;

while (i < 5) {

  console.log(i);

  i++;

}

========================================
РЕЗУЛЬТАТ
========================================

0

1

2

3

4

========================================
КАК РАБОТАЕТ
========================================

i = 0

↓

Проверяется:

i < 5

↓

true

↓

Выводится:

0

↓

i++

↓

i = 1

↓

Повтор проверки

----------------------------------------

Когда

i = 5

условие становится ложным,

и цикл завершается.

========================================
БЕСКОНЕЧНЫЙ ЦИКЛ
========================================

let i = 0;

while (i < 5) {

  console.log(i);

}

========================================
ЧТО ПРОИСХОДИТ
========================================

Значение i
никогда не изменяется.

Поэтому

i < 5

всегда истинно.

Цикл никогда
не завершится.

========================================
СХЕМА
========================================

Проверка условия

↓

true

↓

Выполнение кода

↓

Возврат к проверке

↓

...

↓

false

↓

Конец цикла

========================================
FOR И WHILE
========================================

for

↓

Удобен,

когда заранее известно,

сколько раз
нужно выполнить код.

----------------------------------------

while

↓

Удобен,

когда заранее неизвестно,

сколько повторений потребуется.

Цикл продолжается,

пока условие истинно.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

while выполняет код,

пока условие истинно.

----------------------------------------

Перед каждой итерацией

условие проверяется снова.

----------------------------------------

Если условие сразу ложно,

цикл не выполнится
ни одного раза.

----------------------------------------

Необходимо изменять данные,

от которых зависит условие,

иначе может возникнуть
бесконечный цикл.
