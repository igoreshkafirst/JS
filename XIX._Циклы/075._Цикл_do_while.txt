========================================
75. ЦИКЛ DO...WHILE
========================================

Цикл do...while сначала
выполняет блок кода,

а затем проверяет условие.

========================================
СИНТАКСИС
========================================

do {

  // Код

} while (условие);

========================================
ПРИМЕР 1
========================================

let i = 0;

do {

  console.log(i);

  i++;

} while (i < 5);

========================================
РЕЗУЛЬТАТ
========================================

0

1

2

3

4

========================================
КАК ЭТО РАБОТАЕТ
========================================

Сначала выполняется
код внутри do.

↓

После этого
проверяется условие.

↓

Если условие истинно,

цикл повторяется.

========================================
ПРИМЕР 2
========================================

let i = 10;

do {

  console.log(i);

  i++;

} while (i < 5);

========================================
РЕЗУЛЬТАТ
========================================

10

========================================
ПОЧЕМУ
========================================

Код внутри do

выполняется сразу.

Только после этого
проверяется условие:

10 < 5

↓

false

Цикл завершается.

========================================
СРАВНЕНИЕ
========================================

while

↓

Сначала проверяет условие.

Если оно ложно,

код не выполнится
ни одного раза.

----------------------------------------

do...while

↓

Сначала выполняет код.

Проверка условия
происходит после этого.

Поэтому код выполнится
минимум один раз.

========================================
СХЕМА
========================================

do

↓

Код

↓

Проверка условия

↓

true

↓

Повтор

↓

false

↓

Конец

========================================
ГЛАВНЫЕ ИДЕИ
========================================

do...while сначала
выполняет код.

----------------------------------------

Проверка условия
происходит после выполнения.

----------------------------------------

Код внутри do
всегда выполняется
минимум один раз.

----------------------------------------

Если условие истинно,

цикл продолжается.

========================================
КОНЕЦ РАЗДЕЛА
========================================
