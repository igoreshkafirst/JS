========================================
76. ЦИКЛ FOR...IN
========================================

Цикл for...in используется
для перебора свойств объекта.

========================================
СИНТАКСИС
========================================

for (key in object) {

  // Действия

}

========================================
ПРИМЕР
========================================

const myObject = {
  x: 10,
  y: true,
  z: 'abc',
};

for (const key in myObject) {

  console.log(
    key,
    myObject[key]
  );

}

========================================
РЕЗУЛЬТАТ
========================================

x 10

y true

z abc

========================================
КАК ЭТО РАБОТАЕТ
========================================

Первая итерация

↓

key = 'x'

↓

myObject[key]

↓

10

----------------------------------------

Вторая итерация

↓

key = 'y'

↓

myObject[key]

↓

true

----------------------------------------

Третья итерация

↓

key = 'z'

↓

myObject[key]

↓

abc

========================================
ПОЧЕМУ
ИСПОЛЬЗУЮТСЯ КВАДРАТНЫЕ СКОБКИ
========================================

key —

это переменная.

Поэтому обращение
к свойству выполняется так:

myObject[key]

а не:

myObject.key

----------------------------------------

myObject.key

будет искать свойство
с именем "key",

а не значение переменной.

========================================
СХЕМА
========================================

Объект

↓

x
y
z

↓

for...in

↓

key

↓

myObject[key]

========================================
ГЛАВНЫЕ ИДЕИ
========================================

for...in используется
для перебора свойств объекта.

----------------------------------------

На каждой итерации

key содержит
имя свойства.

----------------------------------------

Значение свойства
получают через

myObject[key].

----------------------------------------

Для обращения по имени,
хранящемуся в переменной,

используются
квадратные скобки.
