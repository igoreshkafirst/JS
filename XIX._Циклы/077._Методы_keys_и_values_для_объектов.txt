========================================
77. МЕТОДЫ Object.keys()
И Object.values()
========================================

Объекты не имеют метода
forEach.

Чтобы перебрать свойства объекта,

используют методы:

Object.keys()

или

Object.values()

========================================
Object.keys()
========================================

Возвращает массив
имён (ключей) объекта.

========================================
ПРИМЕР 1
========================================

const myObject = {
  x: 10,
  y: true,
  z: 'abc',
};

Object.keys(myObject)
  .forEach((key) => {

    console.log(
      key,
      myObject[key]
    );

  });

========================================
РЕЗУЛЬТАТ
========================================

x 10

y true

z abc

========================================
КАК ЭТО РАБОТАЕТ
========================================

Object.keys(myObject)

↓

['x', 'y', 'z']

↓

forEach()

↓

Перебирает каждый ключ.

========================================
Object.values()
========================================

Возвращает массив
значений объекта.

========================================
ПРИМЕР 2
========================================

const myObject = {
  x: 10,
  y: true,
  z: 'abc',
};

Object.values(myObject)
  .forEach((value) => {

    console.log(value);

  });

========================================
РЕЗУЛЬТАТ
========================================

10

true

abc

========================================
КАК ЭТО РАБОТАЕТ
========================================

Object.values(myObject)

↓

[10, true, 'abc']

↓

forEach()

↓

Перебирает каждое значение.

========================================
РАБОТА В КОНСОЛИ
========================================

Object.keys({})

↓

[]

----------------------------------------

Object.keys({
  name: 'Igor'
})

↓

['name']

----------------------------------------

Object.keys({
  name: 'Igor',
  isInstructor: false
})

↓

['name', 'isInstructor']

----------------------------------------

Object.values({})

↓

[]

----------------------------------------

Object.values({
  name: 'Igor'
})

↓

['Igor']

========================================
СРАВНЕНИЕ
========================================

Object.keys()

↓

Возвращает
ключи объекта.

----------------------------------------

Object.values()

↓

Возвращает
значения объекта.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Object.keys()

возвращает массив
ключей объекта.

----------------------------------------

Object.values()

возвращает массив
значений объекта.

----------------------------------------

Полученный массив
можно перебрать
с помощью forEach().

----------------------------------------

Объект сам по себе
не имеет метода forEach().
