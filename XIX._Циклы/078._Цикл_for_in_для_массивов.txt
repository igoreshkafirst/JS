========================================
78. ЦИКЛ FOR...IN ДЛЯ МАССИВОВ
========================================

Цикл for...in может
перебирать массивы,

потому что массив —
это тоже объект.

Однако для массивов
обычно используют
другие способы перебора.

========================================
ПРИМЕР
========================================

const myArray = [
  true,
  10,
  'abc',
  null
];

for (const key in myArray) {

  console.log(
    myArray[key]
  );

}

========================================
РЕЗУЛЬТАТ
========================================

true

10

abc

null

========================================
КАК ЭТО РАБОТАЕТ
========================================

Первая итерация

↓

key = "0"

↓

myArray[0]

↓

true

----------------------------------------

Вторая итерация

↓

key = "1"

↓

myArray[1]

↓

10

----------------------------------------

Третья итерация

↓

key = "2"

↓

myArray[2]

↓

abc

----------------------------------------

Четвёртая итерация

↓

key = "3"

↓

myArray[3]

↓

null

========================================
ПОЧЕМУ ЭТО РАБОТАЕТ
========================================

Массив —

это специальный объект.

Его элементы имеют
имена свойств:

"0"

"1"

"2"

...

Именно их перебирает
for...in.

========================================
НО ЕСТЬ ВАЖНЫЙ МОМЕНТ
========================================

Для массивов

for...in

использовать
не рекомендуется.

Лучше применять:

for

for...of

forEach()

map()

========================================
ГЛАВНЫЕ ИДЕИ
========================================

for...in может
перебирать массив.

----------------------------------------

На каждой итерации

key содержит индекс
элемента массива.

----------------------------------------

Элемент получают через

myArray[key].

----------------------------------------

Для массивов обычно
используют другие способы
перебора.
