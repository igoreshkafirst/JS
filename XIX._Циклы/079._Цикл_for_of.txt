========================================
79. ЦИКЛ FOR...OF
========================================

Цикл for...of используется
для перебора элементов
итерируемых объектов.

Например:

строк;

массивов.

========================================
СИНТАКСИС
========================================

for (element of iterable) {

  // Действия
}

========================================
FOR...OF ДЛЯ СТРОК
========================================

const myString = 'Hey';

for (const letter of myString) {

  console.log(letter);

}

========================================
РЕЗУЛЬТАТ
========================================

H

e

y

========================================
FOR...OF ДЛЯ МАССИВОВ
========================================

const myArray = [
  true,
  10,
  'abc',
  null
];

for (const element of myArray) {

  console.log(element);

}

========================================
РЕЗУЛЬТАТ
========================================

true

10

abc

null

========================================
СРАВНЕНИЕ С forEach
========================================

const myArray = [
  true,
  10,
  'abc',
  null
];

myArray.forEach((element) => {

  console.log(element);

});

========================================
РЕЗУЛЬТАТ
========================================

true

10

abc

null

========================================
FOR...OF НЕ ДЛЯ ОБЪЕКТОВ
========================================

let myObject = {
  x: 10,
  y: true,
  z: 'abc',
};

for (const prop of myObject) {

  console.log(prop);

}

========================================
РЕЗУЛЬТАТ
========================================

TypeError:

myObject is not iterable

========================================
ПОЧЕМУ
========================================

Обычные объекты

не являются
итерируемыми.

Поэтому

for...of

не может их перебирать.

Для объектов используют:

for...in

Object.keys()

Object.values()

========================================
ГЛАВНЫЕ ИДЕИ
========================================

for...of перебирает
элементы коллекции.

----------------------------------------

Работает со строками.

----------------------------------------

Работает с массивами.

----------------------------------------

Не работает
с обычными объектами.

----------------------------------------

Для объектов используют

for...in

или

Object.keys()

Object.values()
