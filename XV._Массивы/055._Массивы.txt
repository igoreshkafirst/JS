========================================
55. МАССИВЫ
========================================

Массив (Array) —
это объект для хранения
упорядоченного набора значений.

========================================
СОЗДАНИЕ МАССИВА
========================================

const myArray = [1, 2, 3];

console.log(myArray);

Результат:

[1, 2, 3]

========================================
СОЗДАНИЕ МАССИВА ЧЕРЕЗ
КОНСТРУКТОР ARRAY
========================================

const myArray2 = new Array(1, 2, 3);

console.log(myArray2);

Результат:

[1, 2, 3]

========================================
ДВА СПОСОБА СОЗДАНИЯ
========================================

Способ 1:

[1, 2, 3]

----------------------------------------

Способ 2:

new Array(1, 2, 3)

----------------------------------------

На практике чаще используется:

[ ]

========================================
СТРУКТУРА МАССИВА
========================================

const myArray = [1, 2, 3];

----------------------------------------

Индексы элементов:

0 → 1

1 → 2

2 → 3

----------------------------------------

Количество элементов:

length = 3

========================================
ИНДЕКСЫ МАССИВА
========================================

Первый элемент массива
всегда имеет индекс:

0

----------------------------------------

Для массива:

[1, 2, 3]

индексы будут:

0
1
2

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

const myArray = [
  1,
  true,
  'Igor'
];

----------------------------------------

myArray

Результат:

[1, true, 'Igor']

========================================
МАССИВ МОЖЕТ ХРАНИТЬ
РАЗНЫЕ ТИПЫ ДАННЫХ
========================================

const myArray = [
  1,
  true,
  'Igor'
];

----------------------------------------

Число:

1

----------------------------------------

Логическое значение:

true

----------------------------------------

Строка:

'Igor'

========================================
СВОЙСТВО LENGTH
========================================

myArray.length

----------------------------------------

Результат:

3

----------------------------------------

length показывает количество
элементов массива.

========================================
ПРИМЕРЫ
========================================

const numbers = [1, 2, 3];

----------------------------------------

const names = [

];

----------------------------------------

const mixed = [

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Массив — это объект для хранения
набора значений.

----------------------------------------

Элементы массива имеют индексы.

----------------------------------------

Нумерация начинается с 0.

----------------------------------------

Массив можно создать:

[] 

или

new Array()

----------------------------------------

Количество элементов хранится
в свойстве:

length

----------------------------------------

В одном массиве могут храниться
значения разных типов.
