========================================
56. ОПЕРАТОР СРАВНЕНИЯ
ДЛЯ МАССИВОВ И ОБЪЕКТОВ
========================================

Массивы и объекты имеют
ссылочный тип данных.

При сравнении JavaScript
сравнивает не содержимое,
а ссылки на объекты.

========================================
РАБОТА В КОНСОЛИ БРАУЗЕРА
========================================

const myArray = [1, true, 'Igor'];

----------------------------------------

myArray

Результат:

(3) [1, true, 'Igor']

----------------------------------------

const myArray2 = [1, true, 'Igor'];

----------------------------------------

myArray2

Результат:

(3) [1, true, 'Igor']

========================================
СРАВНЕНИЕ ДВУХ МАССИВОВ
========================================

myArray === myArray2

Результат:

false

========================================
ПОЧЕМУ FALSE
========================================

Несмотря на одинаковое содержимое:

[1, true, 'Igor']

и

[1, true, 'Igor']

----------------------------------------

это два разных массива.

----------------------------------------

Каждый массив хранится
в своей области памяти.

----------------------------------------

Следовательно ссылки разные.

========================================
СОЗДАНИЕ НОВОЙ ССЫЛКИ
========================================

const myArray3 = myArray;

========================================
СРАВНЕНИЕ ССЫЛОК
========================================

myArray === myArray3

Результат:

true

========================================
ПОЧЕМУ TRUE
========================================

Переменная:

myArray3

получила ссылку на тот же массив.

----------------------------------------

Обе переменные указывают
на один и тот же объект.

========================================
СХЕМА
========================================

myArray
    │
    ▼
[1, true, 'Igor']
    ▲
    │
myArray3

----------------------------------------

myArray2
    │
    ▼
[1, true, 'Igor']

========================================
СРАВНЕНИЕ ПРИМИТИВОВ
========================================

10 === 10

Результат:

true

----------------------------------------

'Igor' === 'Igor'

Результат:

true

========================================
СРАВНЕНИЕ МАССИВОВ
========================================

[1, 2, 3] === [1, 2, 3]

Результат:

false

========================================
СРАВНЕНИЕ ОБЪЕКТОВ
========================================

{ a: 1 } === { a: 1 }

Результат:

false

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Примитивы сравниваются
по значению.

----------------------------------------

Массивы и объекты сравниваются
по ссылке.

----------------------------------------

Два одинаковых массива обычно:

false

----------------------------------------

Две переменные, указывающие
на один и тот же массив:

true

----------------------------------------

Оператор === для объектов
и массивов сравнивает ссылки,
а не содержимое.
