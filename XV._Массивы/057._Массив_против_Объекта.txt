========================================
57. МАССИВ ПРОТИВ ОБЪЕКТА
========================================

Массив в JavaScript является объектом.

Однако массивы и обычные объекты
используются для разных задач.

========================================
ОБЪЕКТ
========================================

const myObject = {
  0: 1,
  1: 2,
  2: 3,
  length: 3,
};

console.log(myObject);

Результат:

{ '0': 1, '1': 2, '2': 3, length: 3 }

========================================
МАССИВ
========================================

const myArray = [1, 2, 3];

console.log(myArray);

Результат:

[1, 2, 3]

========================================
СРАВНЕНИЕ СТРУКТУР
========================================

Объект:

{
  0: 1,
  1: 2,
  2: 3,
  length: 3
}

----------------------------------------

Массив:

[1, 2, 3]

========================================
ЧТО ОБЩЕГО
========================================

Оба могут хранить данные.

----------------------------------------

Оба являются объектами.

----------------------------------------

К элементам можно обращаться
по индексу.

========================================
ПРИМЕР
========================================

myObject[0]

Результат:

1

----------------------------------------

myArray[0]

Результат:

1

========================================
ГЛАВНОЕ ОТЛИЧИЕ
========================================

Объект предназначен для хранения
свойств по именам.

----------------------------------------

Пример:

const user = {
  name: 'Igor',
  age: 25,
};

========================================
ГЛАВНОЕ ОТЛИЧИЕ
========================================

Массив предназначен для хранения
упорядоченного списка значений.

----------------------------------------

Пример:

const numbers = [10, 20, 30];

========================================
СВОЙСТВО LENGTH
========================================

У массива свойство length
обновляется автоматически.

----------------------------------------

const myArray = [1, 2, 3];

myArray.length

Результат:

3

========================================
У ОБЪЕКТА LENGTH
ОБЫЧНО ОТСУТСТВУЕТ
========================================

Если свойство length добавить вручную:

const myObject = {
  length: 3
};

то JavaScript не будет
обновлять его автоматически.

========================================
ПРИМЕР
========================================

const myArray = [1, 2, 3];

typeof myArray

Результат:

'object'

----------------------------------------

Массив является объектом,
но имеет специальные свойства
и методы для работы со списками.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Массив является объектом.

----------------------------------------

Массив используется для хранения
списка значений.

----------------------------------------

Объект используется для хранения
именованных свойств.

----------------------------------------

У массива есть специальные методы.

----------------------------------------

Свойство length массива
обновляется автоматически.
