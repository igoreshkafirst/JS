========================================
58. КАК РАБОТАТЬ
С ЭЛЕМЕНТАМИ МАССИВА
========================================

Элементы массива доступны
по индексам.

Индекс первого элемента:

0

========================================
ЧТЕНИЕ ЗНАЧЕНИЙ ИЗ МАССИВА
========================================

const myArray = [1, true, 'a'];

console.log(myArray);

Результат:

[1, true, 'a']

----------------------------------------

console.log(myArray[0]);

Результат:

1

----------------------------------------

console.log(myArray[1]);

Результат:

true

----------------------------------------

console.log(myArray.length);

Результат:

3

========================================
ИНДЕКСЫ ЭЛЕМЕНТОВ
========================================

const myArray = [1, true, 'a'];

----------------------------------------

0 → 1

1 → true

2 → 'a'

========================================
СВОЙСТВО LENGTH
========================================

length показывает количество
элементов массива.

----------------------------------------

const myArray = [1, true, 'a'];

myArray.length

Результат:

3

========================================
ИЗМЕНЕНИЕ LENGTH
========================================

myArray.length = 7;

----------------------------------------

Результат:

7

----------------------------------------

Массив станет:

▽ (7) [1, true, 'Igor', empty × 4]
    0: 1
    1: true
    2: "Igor"
    length: 7
    ▷ [[Prototype]]: Array(0)

========================================
EMPTY ЭЛЕМЕНТЫ
========================================

empty × 4

означает четыре пустых места
в массиве.

----------------------------------------

Они не содержат значений,
но учитываются в length.

========================================
УМЕНЬШЕНИЕ LENGTH
========================================

myArray.length = 3;

----------------------------------------

Лишние элементы удаляются.

----------------------------------------

Результат:

▽ (3) [1, true, 'Igor']
    0: 1
    1: true
    2: "Igor"
    length: 3
    ▷ [[Prototype]]: Array(0)

========================================
ИЗМЕНЕНИЕ ЭЛЕМЕНТА
========================================

const myArray = [1, 2, 3, 4];

myArray[2] = 'abc';

----------------------------------------

Результат:

[1, 2, 'abc', 4]

----------------------------------------

Значение элемента с индексом 2
заменено на:

'abc'

========================================
ДОБАВЛЕНИЕ ЭЛЕМЕНТА
========================================

myArray[4] = true;

----------------------------------------

Результат:

[1, 2, 'abc', 4, true]

----------------------------------------

Новый элемент добавлен
в конец массива.

========================================
ИЗМЕНЕНИЕ LENGTH
ПОСЛЕ ДОБАВЛЕНИЯ
========================================

myArray.length

Результат:

5

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Элементы массива имеют индексы.

----------------------------------------

Нумерация начинается с 0.

----------------------------------------

Элемент можно получить:

myArray[index]

----------------------------------------

Элемент можно изменить:

myArray[index] = value

----------------------------------------

Свойство length показывает
количество элементов массива.

----------------------------------------

Изменение length может:

- увеличить массив
- уменьшить массив

----------------------------------------

При уменьшении length
лишние элементы удаляются.
