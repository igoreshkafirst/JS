========================================
59. МЕТОДЫ МАССИВОВ
========================================

Массивы имеют встроенные методы.

Методы находятся в:

[[Prototype]]

========================================
ПРОТОТИП МАССИВА
========================================

▽ (3) [1, true, 'Igor']
    0: 1
    1: true
    2: 'Igor'
    length: 3
    ▽ [[Prototype]]: Array(0)

Внутри прототипа находятся методы:

▷ push()
▷ pop()
▷ unshift()
▷ shift()
▷ map()
▷ filter()
▷ find()
▷ forEach()
▷ slice()
▷ sort()

и многие другие.

========================================
PUSH
========================================

Добавляет элементы
в конец массива.

----------------------------------------

const myArray = [1, 2, 3];

myArray.push(4);

Результат:

[1, 2, 3, 4]

----------------------------------------

myArray.push(true);

Результат:

[1, 2, 3, 4, true]

========================================
POP
========================================

Удаляет последний элемент массива.

----------------------------------------

const myArray = [1, 2, 3];

myArray.pop();

Результат:

[1, 2]

----------------------------------------

const removedElement = myArray.pop();

Результат массива:

[1]

----------------------------------------

Значение переменной:

removedElement

Результат:

2

========================================
UNSHIFT
========================================

Добавляет элементы
в начало массива.

----------------------------------------

const myArray = [1, 2, 3];

myArray.unshift(true);

Результат:

[true, 1, 2, 3]

----------------------------------------

myArray.unshift('abc');

Результат:

['abc', true, 1, 2, 3]

========================================
SHIFT
========================================

Удаляет первый элемент массива.

----------------------------------------

const myArray = [1, 2, 3];

myArray.shift();

Результат:

[2, 3]

----------------------------------------

const removedElement = myArray.shift();

Результат массива:

[3]

----------------------------------------

Значение переменной:

removedElement

Результат:

2

========================================
СРАВНЕНИЕ МЕТОДОВ
========================================

push()

Добавляет элемент в конец.

----------------------------------------

pop()

Удаляет элемент с конца.

----------------------------------------

unshift()

Добавляет элемент в начало.

----------------------------------------

shift()

Удаляет элемент из начала.

========================================
СХЕМА
========================================

Начальный массив:

[1, 2, 3]

----------------------------------------

push(4)

[1, 2, 3, 4]

----------------------------------------

pop()

[1, 2]

----------------------------------------

unshift(true)

[true, 1, 2, 3]

----------------------------------------

shift()

[2, 3]

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Методы массивов находятся
в [[Prototype]].

----------------------------------------

push() добавляет элементы в конец.

----------------------------------------

pop() удаляет последний элемент
и возвращает его.

----------------------------------------

unshift() добавляет элементы
в начало массива.

----------------------------------------

shift() удаляет первый элемент
и возвращает его.
