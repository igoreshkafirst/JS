========================================
60. МЕТОД FOREACH
========================================

Метод forEach() используется
для перебора элементов массива.

========================================
СИНТАКСИС
========================================

myArray.forEach(element => {
  // действия с элементом
});

========================================
ПРИМЕР
========================================

const myArray = [1, 2, 3];

console.log(myArray);

Результат:

[1, 2, 3]

----------------------------------------

myArray.forEach(el => console.log(el * 2));

Результат:

2
4
6

----------------------------------------

console.log(myArray);

Результат:

[1, 2, 3]

========================================
ВАЖНО
========================================

Метод forEach() не изменяет
массив автоматически.

----------------------------------------

После выполнения:

myArray.forEach(...)

массив остаётся прежним.

========================================
ПРИМЕР В VS CODE
========================================

const myArray = [1, 2, 3, 10];

console.log(myArray);

const res = myArray.forEach(
  el => console.log(el * 2)
);

console.log(res);

console.log(myArray);

========================================
ВЫВОД В КОНСОЛЬ
========================================

[1, 2, 3, 10]

2
4
6
20

undefined

[1, 2, 3, 10]

========================================
ПОЧЕМУ UNDEFINED
========================================

Метод forEach() ничего
не возвращает.

----------------------------------------

Поэтому:

const res = myArray.forEach(...);

----------------------------------------

После выполнения:

res === undefined

========================================
ЧТО ПОЛУЧАЕТ CALLBACK
========================================

В примере:

myArray.forEach(el => ...)

----------------------------------------

el последовательно принимает
значения элементов массива.

----------------------------------------

Первый вызов:

el = 1

----------------------------------------

Второй вызов:

el = 2

----------------------------------------

Третий вызов:

el = 3

----------------------------------------

Четвертый вызов:

el = 10

========================================
СХЕМА РАБОТЫ
========================================

Массив:

[1, 2, 3, 10]

----------------------------------------

el = 1 → 2

el = 2 → 4

el = 3 → 6

el = 10 → 20

========================================
ГЛАВНЫЕ ИДЕИ
========================================

forEach() перебирает
все элементы массива.

----------------------------------------

Для каждого элемента
вызывается callback-функция.

----------------------------------------

forEach() не создаёт
новый массив.

----------------------------------------

forEach() не возвращает
результат работы.

----------------------------------------

Возвращаемое значение:

undefined
