========================================
61. МЕТОД MAP
========================================

Метод map() перебирает элементы
массива и создаёт новый массив.

========================================
СИНТАКСИС
========================================

const newArray = myArray.map(
  element => {
    return новоеЗначение;
  }
);

========================================
ПРИМЕР
========================================

const myArray = [1, 2, 3];

console.log(myArray);

// [1, 2, 3]

----------------------------------------

const newArray =
  myArray.map(el => el * 3);

----------------------------------------

console.log(newArray);

// [3, 6, 9]

----------------------------------------

console.log(myArray);

// [1, 2, 3]

========================================
ВАЖНО
========================================

Метод map() не изменяет
исходный массив.

----------------------------------------

Создаётся новый массив.

========================================
ПРИМЕР В VS CODE
========================================

const myArray = [1, 2, 3];

console.log(myArray);

const newArray =
  myArray.map(function (el) {
    return el * 3;
  });

console.log(newArray);
console.log(myArray);

========================================
ВЫВОД В КОНСОЛЬ
========================================

[1, 2, 3]

[3, 6, 9]

[1, 2, 3]

========================================
КАК РАБОТАЕТ MAP
========================================

Исходный массив:

[1, 2, 3]

----------------------------------------

Первый элемент:

1 × 3 = 3

----------------------------------------

Второй элемент:

2 × 3 = 6

----------------------------------------

Третий элемент:

3 × 3 = 9

----------------------------------------

Новый массив:

[3, 6, 9]

========================================
СРАВНЕНИЕ FOREACH И MAP
========================================

forEach()

- перебирает массив
- ничего не возвращает
- результат: undefined

----------------------------------------

map()

- перебирает массив
- создаёт новый массив
- возвращает новый массив

========================================
ПРИМЕР
========================================

const numbers = [1, 2, 3];

const doubled =
  numbers.map(el => el * 2);

----------------------------------------

Результат:

[2, 4, 6]

========================================
ГЛАВНЫЕ ИДЕИ
========================================

map() перебирает массив.

----------------------------------------

Для каждого элемента
вызывается callback-функция.

----------------------------------------

Результат callback-функции
попадает в новый массив.

----------------------------------------

Исходный массив
не изменяется.

----------------------------------------

map() возвращает
новый массив.
