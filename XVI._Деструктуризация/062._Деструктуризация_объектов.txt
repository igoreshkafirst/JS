========================================
62. ДЕСТРУКТУРИЗАЦИЯ ОБЪЕКТОВ
========================================

Деструктуризация позволяет
извлекать свойства объекта
в отдельные переменные.

========================================
ОБЫЧНЫЙ СПОСОБ
========================================

const userProfile = {
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false,
};

const name = userProfile.name;
const commentsQty = userProfile.commentsQty;

========================================
ДЕСТРУКТУРИЗАЦИЯ
========================================

const userProfile = {
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false,
};

const { name, commentsQty } = userProfile;

========================================
ПОЛНЫЙ ПРИМЕР
========================================

const userProfile = {
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false,
};

const { name, commentsQty } = userProfile;
const { hasSignedAgreement } = userProfile;

console.log(name); // Igor
console.log(commentsQty); // 23

========================================
ЧТО ПРОИСХОДИТ
========================================

Объект:

{
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false
}

----------------------------------------

После деструктуризации:

const { name, commentsQty } = userProfile;

создаются переменные:

name = 'Igor'

commentsQty = 23

========================================
СХЕМА
========================================

userProfile
│
├─ name
├─ commentsQty
└─ hasSignedAgreement

        ↓

const { name, commentsQty }
        ↓

name = 'Igor'

commentsQty = 23

========================================
ВАЖНО
========================================

Имена переменных должны
совпадать с именами свойств.

----------------------------------------

Работает:

const { name } = userProfile;

----------------------------------------

Не работает:

const { userName } = userProfile;

если свойства userName
в объекте нет.

========================================
ПРЕИМУЩЕСТВО
========================================

Вместо:

const name = userProfile.name;
const commentsQty =
  userProfile.commentsQty;

можно написать:

const { name, commentsQty }
  = userProfile;

Код становится короче.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Деструктуризация позволяет
получать свойства объекта
в отдельные переменные.

----------------------------------------

Используются фигурные скобки:

const { property } = object;

----------------------------------------

Имена переменных должны
совпадать с именами свойств.

----------------------------------------

Деструктуризация сокращает код.
