========================================
63. ДЕСТРУКТУРИЗАЦИЯ МАССИВОВ
========================================

Деструктуризация массива позволяет
получать элементы массива
в отдельные переменные.

========================================
ОБЫЧНЫЙ СПОСОБ
========================================

const fruits = [
  'Apple',
  'Banana'
];

const fruitOne = fruits[0];
const fruitTwo = fruits[1];

========================================
ДЕСТРУКТУРИЗАЦИЯ
========================================

const fruits = [
  'Apple',
  'Banana'
];

const [fruitOne, fruitTwo] = fruits;

========================================
ПОЛНЫЙ ПРИМЕР
========================================

const fruits = [
  'Apple',
  'Banana'
];

const [fruitOne, fruitTwo] = fruits;

console.log(fruitOne); // Apple
console.log(fruitTwo); // Banana

========================================
ЧТО ПРОИСХОДИТ
========================================

Массив:

[
  'Apple',
  'Banana'
]

----------------------------------------

После деструктуризации:

const [fruitOne, fruitTwo]
  = fruits;

создаются переменные:

fruitOne = 'Apple'

fruitTwo = 'Banana'

========================================
СХЕМА
========================================

fruits

0 → 'Apple'
1 → 'Banana'

        ↓

const [fruitOne, fruitTwo]

        ↓

fruitOne = 'Apple'

fruitTwo = 'Banana'

========================================
ВАЖНО
========================================

Для массивов используются
квадратные скобки:

[ ]

----------------------------------------

Для объектов используются
фигурные скобки:

{ }

========================================
СРАВНЕНИЕ
========================================

Объект:

const { name } = userProfile;

----------------------------------------

Массив:

const [fruitOne] = fruits;

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Деструктуризация массива
создаёт переменные из элементов массива.

----------------------------------------

Используются квадратные скобки:

const [a, b] = array;

----------------------------------------

Первый элемент массива
попадает в первую переменную.

----------------------------------------

Второй элемент массива
попадает во вторую переменную.

----------------------------------------

Порядок элементов имеет значение.
