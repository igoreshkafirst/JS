========================================
64. ДЕСТРУКТУРИЗАЦИЯ ПАРАМЕТРОВ ФУНКЦИИ
========================================

При передаче объекта в функцию
можно сразу извлечь нужные свойства
в параметрах функции.

========================================
ОБЫЧНЫЙ СПОСОБ
========================================

const userInfo = (userProfile) => {
  const { name, commentsQty } =
    userProfile;

  // код функции
};

========================================
ДЕСТРУКТУРИЗАЦИЯ В ПАРАМЕТРАХ
========================================

const userInfo = (
  { name, commentsQty }
) => {
  // код функции
};

========================================
ПОЛНЫЙ ПРИМЕР
========================================

const userProfile = {
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false,
};

const userInfo = (
  { name, commentsQty }
) => {

  if (!commentsQty) {
    return `User ${name} has no comments`;
  }

  return `User ${name} has ${commentsQty} comments`;
};

userInfo(userProfile);

========================================
РЕЗУЛЬТАТ
========================================

User Igor has 23 comments

========================================
ЧТО ПРОИСХОДИТ
========================================

В функцию передаётся объект:

{
  name: 'Igor',
  commentsQty: 23,
  hasSignedAgreement: false
}

----------------------------------------

Параметры функции:

({ name, commentsQty })

извлекают свойства:

name

commentsQty

----------------------------------------

После этого внутри функции
можно использовать их как
обычные переменные.

========================================
ПРОВЕРКА УСЛОВИЯ
========================================

if (!commentsQty)

----------------------------------------

Если commentsQty равно:

0
false
null
undefined

условие будет истинным.

----------------------------------------

Тогда функция вернёт:

User Igor has no comments

========================================
СХЕМА
========================================

userProfile
│
├─ name = 'Igor'
├─ commentsQty = 23
└─ hasSignedAgreement = false

           ↓

userInfo({
  name,
  commentsQty
})

           ↓

name = 'Igor'

commentsQty = 23

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Объект можно деструктурировать
прямо в параметрах функции.

----------------------------------------

Используются фигурные скобки:

({ property })

----------------------------------------

Внутри функции свойства становятся
обычными переменными.

----------------------------------------

Такой способ сокращает код.
