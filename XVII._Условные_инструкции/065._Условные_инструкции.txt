========================================
65. УСЛОВНЫЕ ИНСТРУКЦИИ
========================================

Инструкция if позволяет
выполнить блок кода,
если условие истинно.

========================================
СИНТАКСИС
========================================

if (условие) {

  // Код выполнится,
  // если условие истинно

}

========================================
ПРИМЕР
========================================

let val = 10;

if (val > 5) {
  val += 20;
}

console.log(val);

========================================
РЕЗУЛЬТАТ
========================================

30

========================================
КАК ЭТО РАБОТАЕТ
========================================

val = 10

↓

Проверяется условие:

10 > 5

↓

true

↓

Выполняется блок if

↓

val = 30

========================================
ОПЕРАТОР !
========================================

const person = {
  age: 20,
};

if (!person.name) {
  console.log('Имя не указано');
}

========================================
ПОЧЕМУ УСЛОВИЕ ИСТИННО
========================================

У объекта нет свойства:

name

Поэтому:

person.name

имеет значение:

undefined

----------------------------------------

Далее выполняется:

!undefined

↓

true

Поэтому блок if выполняется.

========================================
СХЕМА
========================================

person

{
  age: 20
}

↓

person.name

↓

undefined

↓

!undefined

↓

true

↓

Выполняется if

========================================
ВАЖНО
========================================

if выполняется только один раз.

----------------------------------------

Если условие истинно —
выполняется код внутри блока.

----------------------------------------

Если условие ложно —
блок if пропускается.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

if проверяет условие.

----------------------------------------

Если результат true,
код выполняется.

----------------------------------------

Если результат false,
код пропускается.

----------------------------------------

Оператор !

инвертирует логическое значение.

----------------------------------------

!undefined

равно

true
