========================================
66. УСЛОВНАЯ ИНСТРУКЦИЯ IF ELSE
========================================

Инструкция if...else позволяет
выполнить один из двух
блоков кода.

========================================
СИНТАКСИС
========================================

if (условие) {

  // Выполняется,
  // если условие истинно

} else {

  // Выполняется,
  // если условие ложно

}

========================================
ПРИМЕР
========================================

let val = 10;

if (val < 5) {
  val += 20;
} else {
  val -= 20;
}

console.log(val);

========================================
РЕЗУЛЬТАТ
========================================

-10

========================================
КАК ЭТО РАБОТАЕТ
========================================

Начальное значение:

val = 10

↓

Проверяется условие:

10 < 5

↓

false

↓

Блок if пропускается

↓

Выполняется блок else

↓

val = 10 - 20

↓

val = -10

========================================
СХЕМА
========================================

          Условие

             │

      ┌──────┴──────┐

    true          false

      │              │

   блок if      блок else

========================================
ВАЖНО
========================================

Всегда выполняется
только один блок.

----------------------------------------

Если условие истинно —
выполняется if.

----------------------------------------

Если условие ложно —
выполняется else.

========================================
СРАВНЕНИЕ
========================================

if

если условие ложно,
ничего не происходит.

----------------------------------------

if...else

если условие ложно,
выполняется блок else.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

if...else имеет
две ветви выполнения.

----------------------------------------

Выполняется только
одна из них.

----------------------------------------

true

↓

выполняется if

----------------------------------------

false

↓

выполняется else

КОНЕЦ РАЗДЕЛА
========================================
