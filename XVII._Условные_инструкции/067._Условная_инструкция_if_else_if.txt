========================================
67. УСЛОВНАЯ ИНСТРУКЦИЯ IF ELSE IF
========================================

Конструкция if...else if...else
позволяет проверить
несколько условий подряд.

========================================
СИНТАКСИС
========================================

if (условие1) {

  // Выполняется,
  // если условие1 истинно

} else if (условие2) {

  // Выполняется,
  // если условие2 истинно

} else {

  // Выполняется,
  // если все условия ложны

}

========================================
КАК РАБОТАЕТ
========================================

Сначала проверяется
первое условие.

----------------------------------------

Если оно истинно,
остальные условия
уже не проверяются.

----------------------------------------

Если первое условие ложно,
проверяется второе.

----------------------------------------

Если все условия ложны,
выполняется else.

========================================
ПРИМЕР 1
========================================

const age = 25;

if (age >= 18) {
  console.log('Is adult');
} else if (age >= 12) {
  console.log('Is teenager');
} else {
  console.log('Is child');
}

========================================
РЕЗУЛЬТАТ
========================================

Is adult

========================================
ПОЧЕМУ
========================================

age = 25

↓

25 >= 18

↓

true

↓

Выполняется:

Is adult

↓

Проверка завершается.

========================================
НЕЗАВИСИМЫЕ IF
========================================

Иногда удобнее использовать
несколько отдельных if.

========================================
ПРИМЕР 2
========================================

const age = 25;

if (age >= 18) {
  console.log('Is adult');
}

if (age >= 12 && age < 18) {
  console.log('Is teenager');
}

if (age < 12) {
  console.log('Is child');
}

========================================
ПОЧЕМУ ЗДЕСЬ РАБОТАЕТ
========================================

Каждый if
проверяется отдельно.

----------------------------------------

В данном примере
условия составлены так,
что выполнится только одно.

========================================
СРАВНЕНИЕ
========================================

if...else if...else

↓

Проверка прекращается
после первого true.

----------------------------------------

Несколько отдельных if

↓

Каждое условие
проверяется независимо.

========================================
СХЕМА
========================================

          Условие 1

              │

      ┌───────┴────────┐

    true             false
      │                 │
   выполнить      Условие 2
      │                 │
      │         ┌───────┴────────┐
      │       true            false
      │         │                 │
      │   выполнить            else
      │                           │
      └─────────────── Конец ─────┘

========================================
ГЛАВНЫЕ ИДЕИ
========================================

if...else if...else
используется для проверки
нескольких условий.

----------------------------------------

Проверка прекращается
после первого истинного условия.

----------------------------------------

Если ни одно условие
не выполнено,
срабатывает else.

----------------------------------------

Несколько отдельных if
проверяются независимо
друг от друга.
