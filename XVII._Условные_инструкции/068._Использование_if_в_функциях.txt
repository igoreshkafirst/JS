========================================
68. ИСПОЛЬЗОВАНИЕ IF В ФУНКЦИЯХ
========================================

Условные инструкции часто используются
для проверки аргументов функции.

Если данные некорректны,
функция может сразу завершить работу.

========================================
ПРИМЕР
========================================

const sumPositiveNumbers = (a, b) => {

  if (
    typeof a !== 'number' ||
    typeof b !== 'number'
  ) {
    return 'One of the arguments is not a number';
  }

  if (a <= 0 || b <= 0) {
    return 'Numbers are not positive';
  }

  return a + b;
};

========================================
ЧТО ПРОИСХОДИТ
========================================

Функция выполняет проверки
по порядку.

----------------------------------------

Первая проверка:

typeof a !== 'number'

или

typeof b !== 'number'

----------------------------------------

Если хотя бы один аргумент
не является числом,
функция сразу завершится.

========================================
ВТОРАЯ ПРОВЕРКА
========================================

if (a <= 0 || b <= 0)

----------------------------------------

Если хотя бы одно число
меньше или равно нулю,

функция вернёт сообщение:

Numbers are not positive

========================================
ЕСЛИ ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ
========================================

Выполняется:

return a + b;

Функция возвращает сумму чисел.

========================================
СХЕМА
========================================

Получены аргументы

        │

        ▼

Проверка типов

        │

  есть ошибка?

   ┌────┴────┐

  Да        Нет

  │          │

return      ▼

      Проверка чисел

            │

      Есть неположительное?

        ┌───┴────┐

       Да       Нет

       │         │

    return       ▼

          return a + b

========================================
ПОЧЕМУ RETURN ТАК ВАЖЕН
========================================

После выполнения return

функция сразу прекращает работу.

Код ниже уже не выполняется.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

if позволяет проверять
аргументы функции.

----------------------------------------

return может завершить
функцию раньше времени.

----------------------------------------

Сначала обычно выполняются
проверки данных,

а затем — основная работа функции.

----------------------------------------

Такой подход делает код
более надёжным.
