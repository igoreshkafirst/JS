========================================
70. ТЕРНАРНЫЙ ОПЕРАТОР
========================================

Тернарный оператор —
это сокращённая запись
инструкции if...else.

========================================
СИНТАКСИС
========================================

условие
  ? выражение1
  : выражение2;

========================================
КАК РАБОТАЕТ
========================================

Если условие истинно,

выполняется выражение1.

----------------------------------------

Если условие ложно,

выполняется выражение2.

========================================
ПРИМЕР 1
========================================

const value = 11;

value
  ? console.log('Условие истинно')
  : console.log('Условие ложно');

========================================
РЕЗУЛЬТАТ
========================================

Условие истинно

========================================
ПОЧЕМУ
========================================

Число 11 —

правдивое (truthy) значение.

Поэтому выполняется
первое выражение.

========================================
ПРИМЕР 2
========================================

const value1 = 11;
const value2 = 25;

value1 && value2
  ? myFunction(value1, value2)
  : myFunction();

========================================
ПОЧЕМУ
========================================

value1 && value2

↓

true

↓

Вызывается:

myFunction(value1, value2)

========================================
ПРИМЕР 3
========================================

let value = 11;

console.log(
  value >= 0
    ? value
    : -value
);

value = -5;

const res =
  value >= 0
    ? value
    : -value;

console.log(res);

========================================
РЕЗУЛЬТАТ
========================================

11

5

========================================
ЧТО ПРОИСХОДИТ
========================================

Если число
положительное,

возвращается оно само.

----------------------------------------

Если число
отрицательное,

возвращается:

-value

то есть число
с противоположным знаком.

========================================
СРАВНЕНИЕ
========================================

if...else

if (условие) {
  ...
} else {
  ...
}

----------------------------------------

Тернарный оператор

условие
  ? выражение1
  : выражение2

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Тернарный оператор —

сокращённая форма
if...else.

----------------------------------------

Он всегда содержит:

условие

?

первое выражение

:

второе выражение

----------------------------------------

Если условие истинно,

выполняется первое выражение.

----------------------------------------

Если условие ложно,

выполняется второе выражение.
