========================================
80. МОДУЛИ
========================================

Модули позволяют
разделить программу
на отдельные файлы.

Это делает код более
понятным и удобным
для сопровождения.

========================================
ПРИМЕР СТРУКТУРЫ ПРОЕКТА
========================================

▽ app

  ▽ src

    ▽ modules

      calc.js

      dataRequests.js

      user.js

    index.js

  index.html

========================================
ЗАЧЕМ НУЖНЫ МОДУЛИ
========================================

Каждый файл

отвечает
за свою задачу.

Например:

calc.js

↓

математические функции.

----------------------------------------

user.js

↓

работа с пользователем.

----------------------------------------

dataRequests.js

↓

запросы к серверу.

========================================
IMPORT И EXPORT
========================================

С помощью

export

можно сделать
переменную,
функцию
или объект

доступными
для других файлов.

----------------------------------------

С помощью

import

можно использовать
то, что экспортировано
из другого модуля.

========================================
ПРИМЕР
========================================

moduleOne.js

const myName = () => {

  console.log('Igor');

};

export default myName;

----------------------------------------

moduleTwo.js

import printMyName
from './moduleOne.js';

printMyName();

========================================
РЕЗУЛЬТАТ
========================================

Igor

========================================
КАК ЭТО РАБОТАЕТ
========================================

moduleOne.js

↓

export default

↓

Функция становится
доступной
для других модулей.

----------------------------------------

moduleTwo.js

↓

import

↓

Получает функцию
из moduleOne.js

↓

Можно вызвать её.

========================================
ВАЖНО
========================================

При использовании

import

нужно указывать путь
к файлу.

Например:

'./moduleOne.js'

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Модули позволяют
разделять программу
на несколько файлов.

----------------------------------------

export

делает данные
доступными
для других модулей.

----------------------------------------

import

подключает данные
из другого файла.

----------------------------------------

Современный синтаксис
модулей появился
в ES6 (ES2015).
