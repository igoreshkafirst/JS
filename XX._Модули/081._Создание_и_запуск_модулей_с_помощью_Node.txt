========================================
81. СОЗДАНИЕ И ЗАПУСК МОДУЛЕЙ
С ПОМОЩЬЮ NODE.JS
========================================

Node.js позволяет
создавать программы,
состоящие из нескольких
модулей.

Для этого используются

import

и

export.

========================================
ПРИМЕР
========================================

moduleOne.mjs

const sum = (a, b) =>

  a + b;

export default sum;

----------------------------------------

moduleTwo.mjs

import sumNumbers
from './moduleOne.mjs';

const res1 = sumNumbers(10, 2);

console.log(res1);

const res2 = sumNumbers(5, 10);

console.log(res2);

РЕЗУЛЬТАТ
========================================

========================================
КАК ЭТО РАБОТАЕТ
========================================

moduleOne.mjs

↓

Создаёт функцию

↓

export default

↓

Экспортирует функцию.

----------------------------------------

moduleTwo.mjs

↓

import

↓

Импортирует функцию.

↓

Вызывает её.

↓

Получает результат.

========================================
ПОЧЕМУ .mjs
========================================

Расширение

.mjs

указывает Node.js,

что файл является
ES-модулем.

Поэтому можно
использовать

import

и

export.

========================================
СХЕМА
========================================

moduleOne.mjs

↓

export default

↓

moduleTwo.mjs

↓

import

↓

Вызов функции

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Модули могут
находиться
в разных файлах.

----------------------------------------

export default

экспортирует
значение из модуля.

----------------------------------------

import

подключает
экспортированное значение.

----------------------------------------

В Node.js можно
использовать файлы

.mjs

для работы
с ES-модулями.
