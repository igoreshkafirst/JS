========================================
82. НЕСКОЛЬКО ЭКСПОРТОВ
========================================

Из одного модуля можно
экспортировать
несколько значений.

========================================
ПРИМЕР
========================================

moduleOne.js

const one = 1;

const two = 'two';

export {

  one,

  two

};

----------------------------------------

moduleTwo.js

import {

  one,

  two

} from './moduleOne.js';

console.log(one);

console.log(two);

========================================
РЕЗУЛЬТАТ
========================================

1

two

========================================
КАК ЭТО РАБОТАЕТ
========================================

moduleOne.js

↓

Экспортирует

one

и

two

----------------------------------------

moduleTwo.js

↓

Импортирует

one

и

two

↓

Использует их
в программе.

========================================
ПЕРЕИМЕНОВАНИЕ ИМПОРТА
========================================

moduleTwo.js

import {

  one as oneRenamed,

  two

} from './moduleOne.js';

console.log(oneRenamed);

console.log(two);

========================================
РЕЗУЛЬТАТ
========================================

1

two

========================================
КАК ЭТО РАБОТАЕТ
========================================

one

↓

oneRenamed

----------------------------------------

Имя переменной
изменилось,

но значение
осталось тем же.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Из одного модуля
можно экспортировать
несколько значений.

----------------------------------------

Именованный импорт
использует фигурные скобки.

----------------------------------------

При импорте
можно переименовать
любое значение
с помощью

as.

----------------------------------------

Переименование
изменяет только имя
в текущем модуле.

========================================
КОНЕЦ РАЗДЕЛА
