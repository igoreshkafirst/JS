========================================
84. ПРАКТИКА ПО СОЗДАНИЮ
НЕСКОЛЬКИХ ЭКСПОРТОВ
========================================

Один модуль может
экспортировать
несколько функций.

Другой модуль
может импортировать их
и использовать.

========================================
ПРИМЕР
========================================

moduleOne.mjs

const sum = (a, b) =>

  a + b;

const mult = (a, b) =>

  a * b;

export {

  sum,

  mult

};

----------------------------------------

moduleTwo.mjs

import {

  sum,

  mult as multNumbers

} from './moduleOne.mjs';

console.log(sum(10, 2));

console.log(multNumbers(10, 2));

========================================
РЕЗУЛЬТАТ
========================================

12

20

========================================
КАК ЭТО РАБОТАЕТ
========================================

moduleOne.mjs

↓

Создаются две функции.

↓

sum

↓

mult

↓

Обе экспортируются.

----------------------------------------

moduleTwo.mjs

↓

sum

импортируется
без изменений.

↓

mult

импортируется
под именем

multNumbers.

========================================
ПЕРЕИМЕНОВАНИЕ
========================================

mult

↓

mult as multNumbers

↓

В текущем модуле

функция называется

multNumbers.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Один модуль может
экспортировать
несколько функций.

----------------------------------------

Импортировать можно
как все нужные функции,
так и только некоторые.

----------------------------------------

При импорте
можно изменить имя
с помощью

as.

----------------------------------------

Переименование
не изменяет
исходный модуль.
