========================================
85. СОЗДАНИЕ ПРОЕКТА REACT
========================================

Для создания нового
React-проекта
используется команда

npx create-react-app my-app

========================================
ЧТО ДЕЛАЕТ КОМАНДА
========================================

npx

↓

Запускает пакет,
не устанавливая его
глобально.

----------------------------------------

create-react-app

↓

Создаёт готовый
React-проект.

----------------------------------------

my-app

↓

Имя создаваемой папки
с проектом.

========================================
ПРОЦЕСС СОЗДАНИЯ
========================================

1.

Скачиваются необходимые
пакеты.

↓

2.

Создаётся структура
проекта.

↓

3.

Устанавливаются
зависимости.

↓

4.

Проект готов
к запуску.

========================================
ПОСЛЕ СОЗДАНИЯ
========================================

Перейти в папку
проекта

cd my-app

----------------------------------------

Запустить проект

npm start

========================================
РЕЗУЛЬТАТ
========================================

После запуска

npm start

откроется локальный
сервер разработки
React.

========================================
ВАЖНО
========================================

Во время установки

npm

может сообщить
об уязвимостях
(vulnerabilities).

Это не означает,

что проект создан
неправильно.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

npx запускает пакет.

----------------------------------------

create-react-app
создаёт новый
React-проект.

----------------------------------------

После создания
проекта необходимо
перейти в его папку.

----------------------------------------

Для запуска
используется

npm start.

КОНЕЦ РАЗДЕЛА
