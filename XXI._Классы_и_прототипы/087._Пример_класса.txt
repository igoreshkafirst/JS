========================================
87. ПРИМЕР КЛАССА
========================================

Класс — это шаблон,
по которому создаются
объекты.

========================================
ПРИМЕР
========================================

class Comment {

  constructor(text) {

    this.text = text;

    this.votesQty = 0;

  }

  upvote() {

    this.votesQty += 1;

  }

}

========================================
КОНСТРУКТОР
========================================

constructor()

вызывается автоматически
при создании объекта.

Он используется
для задания
начальных значений
свойств.

========================================
THIS
========================================

this

ссылается
на создаваемый объект.

========================================
СВОЙСТВА
========================================

this.text

↓

текст комментария.

----------------------------------------

this.votesQty

↓

количество голосов.

========================================
МЕТОД
========================================

upvote()

увеличивает значение

votesQty

на единицу.

========================================
КАК ЭТО РАБОТАЕТ
========================================

Создаётся объект

↓

constructor()

↓

text получает
переданное значение

↓

votesQty = 0

↓

Метод

upvote()

увеличивает

votesQty.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Класс описывает
будущие объекты.

----------------------------------------

constructor()

инициализирует
свойства объекта.

----------------------------------------

this

обращается
к текущему объекту.

----------------------------------------

Методы работают
со свойствами объекта
через

this.
