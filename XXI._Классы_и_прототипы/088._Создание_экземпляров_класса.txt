========================================
88. СОЗДАНИЕ ЭКЗЕМПЛЯРОВ КЛАССА
========================================

Для создания объекта
по классу используется

new.

========================================
ПРИМЕР
========================================

const firstComment =
  new Comment(
    'First comment'
  );

console.log(firstComment);

========================================
РЕЗУЛЬТАТ
========================================

▽ Comment

text:
"First comment"

votesQty:
0

▽ [[Prototype]]

constructor:
class Comment

upvote()

========================================
АВТОДОПОЛНЕНИЕ VS CODE
========================================

После ввода

firstComment.

VS Code предлагает
всплывающие подсказки.

В них отображаются

↓

свойства объекта

text

votesQty

и

↓

методы

upvote()

========================================
КАК ЭТО РАБОТАЕТ
========================================

new

↓

Создаёт новый объект.

↓

Вызывает

constructor().

↓

Передаёт аргумент

'First comment'.

↓

Создаёт свойства

text

и

votesQty.

========================================
ПРОТОТИП
========================================

Метод

upvote()

не хранится
в самом объекте.

Он находится
в прототипе класса.

Поэтому все объекты,
созданные по одному классу,

используют
один и тот же метод.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

new создаёт
экземпляр класса.

----------------------------------------

constructor()

вызывается автоматически.

----------------------------------------

Свойства объекта
хранятся
в самом объекте.

----------------------------------------

Методы класса
хранятся
в прототипе.

----------------------------------------

VS Code показывает
в автодополнении

и свойства,

и методы объекта.

========================================
КОНЕЦ РАЗДЕЛА
========================================
