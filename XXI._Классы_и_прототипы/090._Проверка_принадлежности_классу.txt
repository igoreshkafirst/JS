========================================
90. ПРОВЕРКА ПРИНАДЛЕЖНОСТИ
КЛАССУ
========================================

Оператор

instanceof

проверяет,

создан ли объект
с помощью
определённого класса.

========================================
ПРИМЕР
========================================

class Comment {

  constructor(text) {

    this.text = text;

    this.votesQty = 0;

  }

  upvote() {

    this.votesQty += 1;

  }

}

----------------------------------------

const firstComment =

new Comment(
  'First comment'
);

========================================
ПРОВЕРКА
========================================

firstComment
instanceof Comment

↓

true

----------------------------------------

firstComment
instanceof Object

↓

true

========================================
КАК ЭТО РАБОТАЕТ
========================================

instanceof

проверяет,

есть ли

Comment.prototype

в цепочке
прототипов объекта.

Если есть,

возвращается

true.

========================================
ПОЧЕМУ OBJECT ТОЖЕ TRUE
========================================

Цепочка прототипов

↓

firstComment

↓

Comment.prototype

↓

Object.prototype

↓

null

Поэтому объект
является экземпляром

Comment

и

Object.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

instanceof

проверяет
принадлежность объекта
к классу.

----------------------------------------

Результат проверки —

true

или

false.

----------------------------------------

Проверка основана
на цепочке прототипов.

КОНЕЦ РАЗДЕЛА
