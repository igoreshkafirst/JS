========================================
91. ВЫЗОВ УНАСЛЕДОВАННЫХ МЕТОДОВ
========================================

Объект может вызывать
методы,
доступные через
цепочку прототипов.

========================================
ПРИМЕР
========================================

class Comment {

  constructor(text) {

    this.text = text;

    this.votesQty = 0;

  }

  upvote() {

    this.votesQty += 1;

  }

}

----------------------------------------

const firstComment =

new Comment(
  'First comment'
);

========================================
ВЫЗОВ МЕТОДА
========================================

firstComment.upvote();

console.log(
  firstComment.votesQty
);

↓

1

----------------------------------------

firstComment.upvote();

console.log(
  firstComment.votesQty
);

↓

2

========================================
КАК ЭТО РАБОТАЕТ
========================================

firstComment

↓

Вызывает

upvote()

↓

Метод увеличивает

votesQty

на 1.

========================================
ПОСЛЕ КАЖДОГО ВЫЗОВА
========================================

Первый вызов

↓

votesQty = 1

----------------------------------------

Второй вызов

↓

votesQty = 2

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Методы вызываются
через оператор

.

----------------------------------------

Метод может изменять
свойства объекта.

----------------------------------------

Один и тот же метод
можно вызывать
много раз.

========================================
КОНЕЦ РАЗДЕЛА
========================================
