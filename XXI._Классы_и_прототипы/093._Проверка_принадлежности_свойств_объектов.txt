========================================
93. ПРОВЕРКА ПРИНАДЛЕЖНОСТИ
СВОЙСТВ ОБЪЕКТА
========================================

Метод

hasOwnProperty()

проверяет,

принадлежит ли
свойство
самому объекту.

========================================
ПРИМЕР
========================================

const firstComment =

new Comment(
  'First comment'
);

========================================
ПРОВЕРКА
========================================

firstComment
.hasOwnProperty('text')

↓

true

----------------------------------------

firstComment
.hasOwnProperty('votesQty')

↓

true

----------------------------------------

firstComment
.hasOwnProperty('upvote')

↓

false

----------------------------------------

firstComment
.hasOwnProperty('hasOwnProperty')

↓

false

========================================
ПОЧЕМУ
========================================

text

и

votesQty

создаются
в constructor().

Поэтому они
принадлежат объекту.

----------------------------------------

upvote()

находится

в Comment.prototype.

----------------------------------------

hasOwnProperty()

находится

в Object.prototype.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

hasOwnProperty()

проверяет
только собственные
свойства объекта.

----------------------------------------

Свойства из prototype
не учитываются.

----------------------------------------

Результат проверки —

true

или

false.
