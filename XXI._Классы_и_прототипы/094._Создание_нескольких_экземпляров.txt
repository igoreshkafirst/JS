ЭКЗЕМПЛЯРОВ

По одному классу

можно создать

любое количество
экземпляров.

========================================
ПРИМЕР
========================================

const firstComment =

new Comment(
  'First comment'
);

----------------------------------------

const secondComment =

new Comment(
  'Second comment'
);

----------------------------------------

const thirdComment =

new Comment(
  'Third comment'
);

========================================

свойства.

----------------------------------------

text

votesQty

Comment.prototype.

данные.
