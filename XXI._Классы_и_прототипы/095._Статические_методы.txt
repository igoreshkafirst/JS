========================================
95. СТАТИЧЕСКИЕ МЕТОДЫ
========================================

Статический метод

принадлежит
классу,

а не экземпляру.

========================================
ОБЪЯВЛЕНИЕ
========================================

class Comment {

  static mergeComments(
    first,
    second
  ) {

    return `${first} ${second}`;

  }

}

========================================
ВЫЗОВ
========================================

Comment.mergeComments(

  'First comment',

  'Second comment'

);

↓

'First comment Second comment'

========================================
ОБЫЧНЫЙ И
СТАТИЧЕСКИЙ МЕТОД
========================================

Обычный метод

↓

вызывается
у объекта.

----------------------------------------

Статический метод

↓

вызывается
у класса.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

static

создаёт
статический метод.

----------------------------------------

Статические методы

не принадлежат
экземплярам.

----------------------------------------

Для вызова

не нужен

new.
