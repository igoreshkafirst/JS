========================================
97. РАСШИРЕНИЕ
ДРУГИХ КЛАССОВ
========================================

Класс может
наследоваться

от другого класса

с помощью

extends.

========================================
ПРИМЕР
========================================

class NumbersArray

extends Array {

  sum() {

    return this.reduce(
      (acc, el) => acc + el,
      0
    );

  }

}

========================================
СОЗДАНИЕ ОБЪЕКТА
========================================

const myArray =

new NumbersArray(
  2,
  5,
  7
);

========================================
ВЫЗОВ МЕТОДА
========================================

myArray.sum()

↓

14

========================================
ЧТО ПОЛУЧИЛ
NumbersArray
========================================

Все методы

Array

+

свой метод

sum().

========================================
ЦЕПОЧКА
ПРОТОТИПОВ
========================================

myArray

↓

NumbersArray.prototype

↓

Array.prototype

↓

Object.prototype

↓

null

========================================
ГЛАВНЫЕ ИДЕИ
========================================

создаёт наследование.
