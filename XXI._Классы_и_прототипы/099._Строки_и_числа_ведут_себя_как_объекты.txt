Строка

является

примитивом.

========================================
ПРИМЕР
========================================

const myName =

'Igor'

========================================
ВЫЗОВ МЕТОДА
========================================

myName
.toLocaleUpperCase()

↓

'IGOR'

========================================
ПОЧЕМУ ЭТО
РАБОТАЕТ
========================================

JavaScript

временно создаёт

объект String.

----------------------------------------

Вызывает метод.

----------------------------------------

После этого

временный объект

удаляется.

========================================
СОЗДАНИЕ
ОБЪЕКТА STRING
========================================

const mySecondName =

new String(
  'Mr First'
);

========================================
РЕЗУЛЬТАТ
========================================

Получается

объект

String.

========================================
ОТЛИЧИЕ
========================================

'Igor'

↓

примитив

----------------------------------------

new String('Igor')

↓

объект

========================================
ГЛАВНЫЕ ИДЕИ
========================================

Строки

умеют вызывать
методы.

----------------------------------------

JavaScript

делает это

через временный

----------------------------------------

new String()
