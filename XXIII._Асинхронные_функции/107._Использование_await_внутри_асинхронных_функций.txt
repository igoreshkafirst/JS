========================================
107. ОПЕРАТОР await
========================================

await

используется

для ожидания

выполнения

Promise.

========================================
СИНТАКСИС
========================================

const asyncFn = async () => {
    await promise;
};

========================================
ВАЖНО
========================================

await

можно использовать

только

внутри

async-функции.

========================================
ПРИНЦИП РАБОТЫ
========================================

await

приостанавливает

выполнение

функции,

пока

Promise

не завершится.

========================================
СХЕМА
========================================

async

↓

await

↓

ожидание Promise

↓

Promise выполнен

↓

следующая инструкция

========================================
ГЛАВНЫЕ ИДЕИ
========================================

await

работает

только

с Promise.

----------------------------------------

await

используется

внутри

async-функций.

----------------------------------------

После выполнения

Promise

код

продолжает

работу.
