========================================
109. ПЕРЕХОД
С Promise
НА async/await
========================================

Вместо

.then()

используется

await.

========================================
СХЕМА
========================================

await fetch()

↓

Response

↓

await response.json()

↓

JSON

↓

return

========================================
ВАЖНО
========================================

async-функция

всегда

возвращает

Promise.

========================================
await
========================================

await

ожидает

завершения

Promise.

========================================
Top-Level Await
========================================

await

вне функции

можно использовать

только

в ES-модулях

или

внутри

async-функции.

========================================
ОБРАБОТКА
ОШИБОК
========================================

При использовании

async/await

обычно

используют

try...catch.

========================================
ГЛАВНЫЕ ИДЕИ
========================================

await

заменяет

.then().

----------------------------------------

return

автоматически

становится

Promise.

----------------------------------------

Для обработки

ошибок

используется

try...catch.
