<Card
  style={{
    backgroundColor: `rgb(${initialColor}, ${opacity})`,
  }}
  className="m-2"
>
  <Card.img
    variant="top"
    style={
      imageLoaded
        ? { opacity: 1, transition: 'opacity 2s ease-in-out' }
        : { opacity: 0 }
    }
    src={image}
    alt={title}
    onLoad={() => setImageLoaded(true)}
  />
</Card>;

В этом примере JSX используется для создания карточки с изображением. Главное — понять, что JSX позволяет смешивать разметку, похожую на HTML, с JavaScript-выражениями.

## Разберём пример по частям

### 1. Компонент `Card`

```
<Card
  className="m-2"
>
  ...
</Card>
```

`Card` — React-компонент. Он получает свойства (`props`), а между открывающим и закрывающим тегами находится его содержимое — `children`.

`className="m-2"` задаёт CSS-класс. В JSX используется `className`, а не HTML-атрибут `class`. Класс `m-2`, вероятно, относится к Bootstrap или другой CSS-библиотеке, которая подключена в проекте.

### 2. JavaScript внутри JSX

```
style={{
  backgroundColor: `rgb(${initialColor}, ${opacity})`,
}}
```

Здесь сразу несколько конструкций:

- Внешние `{}` позволяют вставить JavaScript-выражение в JSX.
- Внутренние `{}` создают JavaScript-объект со стилями.
- `backgroundColor` — CSS-свойство в camelCase, как принято в React.
- Обратные кавычки создают шаблонную строку, а `${...}` вставляет значения переменных.

Обрати внимание: выражение `rgb(${initialColor}, ${opacity})` выглядит подозрительно. Обычный `rgb()` задаёт три цветовых канала — красный, зелёный и синий. Если ты хочешь управлять прозрачностью через `opacity`, её обычно задают отдельным CSS-свойством `opacity` или используют `rgba()` с четырьмя компонентами.

### 3. Условный выбор стиля изображения

```
style={
  imageLoaded
    ? { opacity: 1, transition: 'opacity 2s ease-in-out' }
    : { opacity: 0 }
}
```

Это тернарный оператор JavaScript:

```
условие ? значениеЕслиИстина : значениеЕслиЛожь
```

Если `imageLoaded` истинно, изображение становится непрозрачным (`opacity: 1`), причём появление занимает две секунды. Если ложно, задаётся `opacity: 0` — изображение невидимо.

Такой приём часто используют для плавного появления загружаемой картинки.

### 4. Остальные свойства `Card.img`

```
<Card.img
  variant="top"
  src={image}
  alt={title}
  onLoad={() => setImageLoaded(true)}
/>
```

`Card.img` записан через точку: это компонент `img`, доступный через `Card`. Это специальная форма записи, которую поддерживает конкретная библиотека компонентов; она не является обязательным синтаксисом React для изображений.

| Свойство        | Назначение                                                                  |
| --------------- | --------------------------------------------------------------------------- |
| `variant="top"` | Передаёт строку `top`, обычно для расположения изображения сверху карточки. |
| `src={image}`   | Передаёт значение переменной `image` в качестве адреса изображения.         |
| `alt={title}`   | Передаёт текстовое описание изображения из `title`.                         |
| `onLoad={...}`  | Указывает функцию, которую React вызовет при загрузке изображения.          |

Когда изображение загрузится, выполнится:

```
onLoad={() => setImageLoaded(true)}
```

Это стрелочная функция. Она вызывает `setImageLoaded(true)`, вероятно, обновляя состояние React. После изменения состояния React повторно отрисует компонент, и условие `imageLoaded` позволит показать изображение.

## Что здесь важно запомнить

В этом JSX примере используются сразу четыре вещи:

- Компоненты: `Card` и `Card.img`.
- Props: `className`, `variant`, `src`, `alt`, `style`, `onLoad`.
- JavaScript-выражения в JSX: фигурные скобки `{}`.
- Условный рендеринг стиля: тернарный оператор и состояние загрузки изображения.

Главный принцип: в JSX разметка записывается как HTML-подобный код, а для вычислений, переменных и функций используются фигурные скобки.
