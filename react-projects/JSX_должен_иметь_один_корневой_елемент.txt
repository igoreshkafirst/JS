return (
  <div>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
    <Footer text={text} />
  </div>
);

return (
  <h1>JSX в React</h1>
  <p>JSX похож на HTML</p>
)

В React выражение JSX должно иметь один корневой элемент. Все остальные элементы должны находиться внутри него.

### Пример №1 — правильно ✅

```
return (
  <div>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
    <Footer text={text} />
  </div>
);
```

Здесь `<div>` — корневой элемент. Внутри него находятся заголовок, абзац и компонент `Footer`.

### Пример №2 — неправильно ❌

```
return (
  <h1>JSX в React</h1>
  <p>JSX похож на HTML</p>
);
```

Здесь два соседних элемента — `<h1>` и `<p>` — находятся на одном уровне, но не объединены общим родительским элементом. Поэтому JSX не может разобрать это выражение как один корректный элемент.

### Как исправить пример №2

Можно использовать `<div>`:

```
return (
  <div>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
  </div>
);
```

Или фрагмент React — если дополнительный DOM-элемент не нужен:

```
return (
  <>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
  </>
);
```

Фрагмент `<>...</>` группирует элементы, но не создаёт дополнительный элемент в DOM.

Главное правило: один `return` с JSX должен возвращать одно корневое JSX-выражение. Это может быть обычный элемент, пользовательский компонент или фрагмент.

return {
  React.createElement("h1", null, "JSX в React")
  React.createElement("p", null, "JSX похож на HTML")
}

return{
  <h1>JSX в React</h1>
  <p>JSX похож на HTML</p>
}

Оба примера содержат ошибки: правило одного корневого элемента относится и к JSX, и к элементам, созданным через `React.createElement()`.

## Пример №3 — `React.createElement()`

Исходный вариант неверен:

```
return {
  React.createElement("h1", null, "JSX в React")
  React.createElement("p", null, "JSX похож на HTML")
}
```

Здесь две проблемы:

- Фигурные скобки `{}` не объединяют React-элементы в один корневой элемент. В JavaScript они используются, например, для записи объекта.
- Два вызова `React.createElement()` не объединены в один допустимый элемент.

Правильный вариант с корневым `div`:

```
return React.createElement(
  "div",
  null,
  React.createElement("h1", null, "JSX в React"),
  React.createElement("p", null, "JSX похож на HTML")
);
```

Первый аргумент внешнего вызова — `"div"`, второй — `null` (свойств нет), третий и четвёртый — дочерние элементы.

## Пример №4 — JSX

Исходный вариант тоже неверен:

```
return {
  <h1>JSX в React</h1>
  <p>JSX похож на HTML</p>
}
```

Здесь JSX-элементы не имеют общего корня, а фигурные скобки не предназначены для группировки JSX.

Можно исправить с помощью `div`:

```
return (
  <div>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
  </div>
);
```

Или использовать фрагмент React, если дополнительный HTML-элемент не нужен:

```
return (
  <>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
  </>
);
```

Запомни: один `return` должен возвращать одно корневое выражение. Несколько соседних элементов можно объединить через родительский элемент (`div`) или фрагмент (`<>...</>`).
