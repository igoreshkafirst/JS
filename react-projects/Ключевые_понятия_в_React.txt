Это четыре ключевых понятия React. Давай разберём их так, чтобы было понятно не только определение каждого термина, но и связь между ними.

## 1. Components — компоненты

Компонент — самостоятельная часть пользовательского интерфейса. Например, кнопка, карточка цитаты или всё приложение с цитатами.

```
function Quote() {
  return <p>Stay hungry, stay foolish.</p>;
}
```

Здесь `Quote` — компонент, который описывает, как должна выглядеть часть интерфейса.

## 2. JSX — JavaScript Syntax Extension

JSX — синтаксическое расширение JavaScript, позволяющее записывать разметку, похожую на HTML, прямо в JavaScript-коде.

```
const element = <h1>Hello, React!</h1>;
```

Выражение `<h1>Hello, React!</h1>` выглядит как HTML, но в этом примере оно записано внутри JavaScript с использованием JSX.

## 3. Props — свойства

Props — данные, которые компонент получает от родительского компонента. С их помощью можно использовать один компонент с разными данными.

```
function Quote(props) {
  return <p>{props.text}</p>;
}

function App() {
  return <Quote text="Hello, React!" />;
}
```

Компонент `App` передаёт свойство `text` компоненту `Quote`. Внутри `Quote` значение доступно через `props.text`.

## 4. State — состояние

State — данные, которые компонент хранит и может изменять в процессе работы приложения. Когда состояние меняется, React обновляет интерфейс в зависимости от нового значения.

```
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Нажатий: {count}
    </button>
  );
}
```

Здесь `count` — текущее состояние счётчика, а `setCount` — функция изменения состояния.

## Как связаны эти понятия?

Component

Описывает часть интерфейса

JSX

Описывает разметку компонента

Props

Данные, полученные от родителя.

State

Данные, которыми компонент управляет в процессе работы.

Главное различие для запоминания:

- Props — компонент получает данные извне.
- State — компонент хранит собственные изменяемые данные.
- JSX — способ описания разметки.
- Component — элемент организации приложения.

Эти понятия тесно связаны: компонент получает `props`, хранит при необходимости `state` и описывает интерфейс с помощью JSX.
