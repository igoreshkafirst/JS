useState
useEffect

Два основных React-хука, которые стоит понять в первую очередь, — `useState` и `useEffect`.

## 1. `useState` — состояние компонента

`useState` позволяет компоненту хранить данные и обновлять интерфейс при их изменении.

Пример — счётчик:

```
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Нажатий: {count}
    </button>
  );
}
```

Разберём эту строку:

```
const [count, setCount] = useState(0);
```

- `useState(0)` — создаёт состояние с начальным значением `0`.
- `count` — текущее значение состояния.
- `setCount` — функция, с помощью которой состояние обновляется.

Когда пользователь нажимает кнопку, вызывается `setCount(count + 1)`. React обновляет состояние и повторно отображает компонент с новым значением.

Запомни: для изменения состояния используй функцию обновления, например `setCount()`, а не присваивание `count = count + 1`.

## 2. `useEffect` — побочные эффекты

`useEffect` позволяет выполнять действия, связанные с внешним миром, после отображения компонента. Например, получать данные с сервера, подписываться на события или запускать таймеры.

Пример:

```
import { useEffect, useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Нажатий: ${count}`;
  }, [count]);

  return (
    <button onClick={() => setCount(count + 1)}>
      Нажатий: {count}
    </button>
  );
}
```

Здесь:

```
useEffect(() => {
  document.title = `Нажатий: ${count}`;
}, [count]);
```

После первоначального отображения компонента эффект устанавливает заголовок вкладки браузера. Затем он запускается снова, когда изменяется `count`.

Массив `[count]` называется массивом зависимостей: он указывает, какие значения должны вызвать повторное выполнение эффекта.

### Как работает `useEffect`

| Запись                              | Когда выполняется эффект                      |
| ----------------------------------- | --------------------------------------------- |
| `useEffect(() => { ... })`          | После каждого отображения компонента          |
| `useEffect(() => { ... }, [])`      | После первоначального монтирования компонента |
| `useEffect(() => { ... }, [count])` | После монтирования и при изменении `count`    |

При разработке в режиме `StrictMode` React может дополнительно запускать эффекты в целях проверки. Поэтому на практике не следует предполагать, что эффект с пустым массивом зависимостей выполнится строго один раз при любых условиях.

## Главное различие

- `useState` хранит изменяемые данные компонента.
- `useEffect` выполняет побочные действия, связанные с отображением компонента и изменением его зависимостей.

В нашем примере `useState` хранит количество нажатий, а `useEffect` синхронизирует заголовок вкладки с этим значением.

Правило для обоих хуков: вызывай их на верхнем уровне функционального компонента или пользовательского хука, а не внутри условий, циклов или вложенных функций.
