return (
  <div>
    <h1>JSX в React</h1>
    <p>JSX похож на HTML</p>
    <Footer text={text} />
  </div>
);

В JSX компоненты различают по регистру первой буквы.

### 1. Встроенные элементы

```
<div>
  <h1>JSX в React</h1>
  <p>JSX похож на HTML</p>
</div>
```

`div`, `h1` и `p` начинаются с маленькой буквы. React воспринимает их как встроенные HTML-элементы и создаёт соответствующие DOM-элементы.

### 2. Пользовательский компонент

```
<Footer text={text} />
```

`Footer` начинается с заглавной буквы. Это пользовательский React-компонент, который должен быть определён или импортирован.

`text={text}` — передача свойства (`prop`) компоненту `Footer`: имя свойства — `text`, а его значение берётся из переменной `text`.

Например, компонент может выглядеть так:

```
function Footer(props) {
  return <footer>{props.text}</footer>;
}
```

### Главное правило

- `div`, `h1`, `p` — встроенные элементы, начинаются с маленькой буквы.
- `Footer`, `App`, `Quote` — пользовательские компоненты, начинаются с заглавной буквы.

В твоём примере все эти элементы объединены внутри одного `return`: React отображает заголовок, абзац и пользовательский компонент `Footer`, которому передаётся свойство `text`.
