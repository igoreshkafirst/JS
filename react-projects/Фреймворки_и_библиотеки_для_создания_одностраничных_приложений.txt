Для создания одностраничных приложений (SPA — Single-Page Applications) используют JavaScript-библиотеки и фреймворки. Они помогают обновлять интерфейс без полной перезагрузки страницы.

## Основные технологии

| Технология | Что это                            | Кратко                                                                                                                               |
| ---------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| React      | Библиотека JavaScript              | Создание интерфейса из компонентов. Использует JSX, props, state и хуки, например `useState` и `useEffect`.                          |
| Angular    | Фреймворк                          | Предоставляет комплексный набор инструментов для создания приложений: компоненты, маршрутизацию, формы и другие возможности.         |
| Vue        | Прогрессивный JavaScript-фреймворк | Позволяет постепенно добавлять реактивность и компоненты к интерфейсу или строить полноценное SPA.                                   |
| Svelte     | UI-фреймворк с компиляцией         | Преобразует компоненты в JavaScript-код на этапе сборки приложения.                                                                  |
| Ember      | JavaScript-фреймворк               | Предоставляет структуру и соглашения для создания полноценных веб-приложений.                                                        |
| Ruby       | Язык программирования              | Сам по себе не является библиотекой или фреймворком для SPA. Ruby часто используют на сервере, например с фреймворком Ruby on Rails. |

## Библиотека и фреймворк — в чём разница?

Библиотека предоставляет инструменты, которые разработчик вызывает там, где они нужны. React относится именно к этой категории.

Фреймворк задаёт более полную структуру приложения и определяет многие правила организации кода. Angular и Ember — примеры таких фреймворков.

Vue занимает промежуточное положение по стилю использования: его можно внедрять постепенно или применять для разработки целого приложения. Svelte использует компиляцию компонентов, чтобы подготовить код для браузера.

Для твоего курса главный ориентир — React. Ты уже разбираешь его ключевые понятия: компоненты, JSX, props и state. Остальные технологии из списка можно пока узнавать на уровне того, чем они отличаются от React.
